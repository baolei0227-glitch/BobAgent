# BobWork 便签与笔记使用说明

BobWork 有两套"笔记"体系，定位完全不同，本说明分别讲清它们的新建方式与查看方式。

| | 画布便签（Sticky Notes） | 全局笔记库（Notebook） |
|---|---|---|
| 定位 | 项目内的便利贴（待办清单） | 跨项目的个人笔记 |
| 作用域 | 按项目隔离 | 全局，独立于项目 |
| 存储位置 | `<项目根>/sticky-notes/sticky-notes.json` | `~/BobWork/wanted/notebook.json` |
| 是否随项目删除 | 是（项目没了便签没了） | 否（删除项目前自动迁走） |

---

## 一、画布便签（Sticky Notes）

画布上的便利贴，贴在画布任意位置，可拖拽、缩放、编辑。每张便签有两种视图：

- **TODO 清单**（绿色便签）：可勾选的待办列表
- **NOTE 系统笔记**（黄色便签）：书写笔记，内容自动存入全局笔记库

### 新建方式

| 方式 | 操作 | 说明 |
|---|---|---|
| ① 新建 TODO 便签 | 画布空白处**右键 → Sticky Note → Todo** | 绿色清单便签 |
| ② 新建 NOTE 便签 | 画布空白处**右键 → Sticky Note → Note** | 黄色笔记便签，创建后自动进入笔记编辑 |
| ③ 便签内加页 | 展开便签 → 左侧 **Pages** 栏 → **"＋" New page** | 同一张便签内新增页面（非新便签） |

> 提示：AI 工具在某些场景也会静默创建 TODO 便签（无需手动操作）。

### 查看与编辑

- 便签作为**贴纸直接贴在画布上**，随时可见；点击展开进行编辑
- 展开后顶部有 **TODO / NOTE** 标签，点击切换当前便签的视图
- 便签内部左侧 **Pages** 侧栏默认折叠，展开后可切换页面、重命名页面、加新页
- 便签可**拖拽移动**、**拖动边缘调整大小**
- TODO 项全部勾选后，便签变灰置半透明；单个条目可打勾/取消
- 便签内容**实时自动保存**，保存成功会有短暂提示

### 项目边界

- 便签按项目隔离：`<项目根>/sticky-notes/sticky-notes.json`
- **删除项目**会同时删除该项目的便签；但其中的 **NOTE 笔记内容会在删除前自动迁移到全局笔记库**，不丢失
- 便签是**纯私有**区域：AI 无法读取便签内容

---

## 二、全局笔记库（Notebook）

跨项目的个人笔记，由 AI 自动分类整理，独立于任何项目。

### 新建方式

| 方式 | 操作 | 说明 |
|---|---|---|
| ① 便签 NOTE 视图 | 新建黄色 NOTE 便签直接书写 | 内容经 AI 分类后存入笔记库 |
| ② `/note` 指令 | 在 **WANTED 输入栏**输入 `/note <内容>` | AI 自动分类（如"便签/工作/想法"）并存入笔记库 |

### 查看方式

| 方式 | 说明 |
|---|---|
| ① 便签 NOTE 视图 | 与该条笔记关联的黄色便签可查看/继续编辑 |
| ② 对话让 AI 读取 | 在对话中直接说"**查看我的笔记**"——AI 会调用 `read_notebook` 返回分类目录或全文 |
| ③ 原始文件 | `~/BobWork/wanted/notebook.json`（结构化 JSON） |

### 跨项目特性

- 笔记存于 `~/BobWork/wanted/notebook.json`（应用根级），**与项目完全解耦**
- 切换项目、删除项目、重建项目均不影响笔记
- 删除项目、彻底删除项目前，系统都会**自动兜底迁移**便签中的 NOTE 内容到笔记库，防止丢失
- AI 仅在用户明确要求查阅/修改/删除笔记时才允许读写（`read_notebook` / `update_notebook` / `delete_notebook`）

## 三、两套体系的关系

```
画布便签（项目内）                全局笔记库（跨项目）
┌──────────────────┐             ┌──────────────────────┐
│ TODO 清单（绿）    │ ← 项目隔离   │                      │
│ NOTE 笔记（黄） ──┼──AI分类──→  │ wanted/notebook.json │
└──────────────────┘  迁移/写入    └──────────────────────┘
      │ 删除项目前自动迁移
      └──────────→ 笔记保留，便签删除
```

一句话记忆：

- **临时待办 → 画布 TODO 便签**（随项目走）
- **想留存的笔记 → 黄色 NOTE 便签 或 `/note` 指令**（进全局笔记库，永久保留）

## 四、常见问题

**Q：便签不见了？**
检查是否切换了项目——便签按项目隔离，不同项目看不到彼此的便签。

**Q：删除项目后笔记还在吗？**
黄色 NOTE 笔记内容会在删除前自动迁移到全局笔记库，永久保留；TODO 清单随项目删除。

**Q：能让 AI 帮我记笔记吗？**
可以。直接对话说"把 XXX 记到我的笔记里"，AI 会调用笔记相关工具分类保存；但 AI 不能读写画布便签（私有区）。

**Q：笔记如何分类的？**
`/note` 指令和 NOTE 便签的内容由 AI 自动归类（如"便签/工作/想法"），可在笔记库分类目录中查看。
