## 气质与意象

**意象锚点**：一张铺展开的白色宣纸，纸面微微透出温润的纤维纹理，光线下若有若无的颗粒感是手工造纸的痕迹。每个 AI 对话节点像纸面上晕开的一笔墨痕，赤陶橙的按钮如同印章落款，在素净的纸面上点下一抹暖意。

**关键词**：素净、宣纸、温润、暖意、克制

**场景叙述**：想象一张铺满桌面的白色宣纸，纯净的白底中透出极淡的暖调与纤维纹理。当你点击纸面，一张与底纸同色的卡片悄然浮现，边缘带着柔和的投影。卡片四周的赤陶橙小圆点如墨迹般洇开，邀请你向新的方向书写。AI 的回复以衬线字体逐字呈现，像钢笔在纸面沙沙游走，连接线则是手绘般的弧线，带着赤陶色的温度。

## 视觉策略

- **画布背景**：白色宣纸底色（微暖白调），叠加 SVG 噪声纹理模拟宣纸细腻质感
- **节点卡片**：与画布同色的微透纸面，细边框，轻柔投影，衬线字体
- **连接线**：手绘感弧线，赤陶色调，选中时加深
- **引导标识**：赤陶橙圆形按钮，hover 时加深扩散，带柔和外发光
- **按钮**：赤陶橙实色填充，hover 加深，圆角，白色文字

## 字体排版

- **字体族**：`'Noto Serif SC', 'Songti SC', 'SimSun', Georgia, 'Times New Roman', serif`（中文衬线优先，温润书卷气）
- **节点标题**：12px / 600 weight，字间距略宽
- **消息正文**：13px / 400 weight，行高 1.65，衬线体
- **输入框**：13px / 400 weight，placeholder 用低对比度暖灰
- **按钮文字**：12px / 600 weight，白色

## 动效与交互

- **节点出现**：scale 0.85 -> 1 + opacity 0 -> 1，220ms ease-out，像便签轻轻落下
- **引导标识 hover**：位于节点外部，默认隐藏；鼠标悬停节点 400ms 后淡入显示，离开时 120ms 快速消失；按钮自身 hover 加深背景 + 赤陶色外发光
- **AI 流式输出**：逐字渲染，衬线字体如钢笔书写
- **画布拖拽**：惯性滑动，阻尼感
- **缩放**：以鼠标位置为中心，平滑插值

## 设计禁忌

- 不要使用纯白 `#fff`，永远带一点微暖底调
- 不要使用冷色调（蓝/青/紫），保持整体暖色温
- 不要在节点卡片上使用厚重阴影，保持纸张的轻盈贴合感
- 不要使用蓝紫渐变——用赤陶橙作为唯一强调色
- 不要使用无衬线字体，衬线体是整体气质的核心
- 节点不要太大，保持 320px 宽度，让画布能容纳更多节点
- 不要使用奶油黄底色，画布保持白色宣纸调
