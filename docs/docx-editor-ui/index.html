这张对比稿改了什么（都能落在现有 Token 体系内，不新增依赖）

  • 加表面层次：chrome 由 var(--paper)（#f7f7f8）改为 #fff + --line-soft 描边，画布用 var(--canvas-bg)（#e8e8e8），白纸落在最上层 —— 三级亮度差取代现在的「一片灰」。
  • 文字换图标：项目已装 lucide-react 但完全没用；「左/中/右/两端/增行/删行」等中文词按钮换成 16px 线性图标 + title，B/I/U/S 保留字形（与 Word 一致）。
  • Ribbon 固定高 + 分组：去掉 flexWrap:'wrap'，改 66px 固定组行 + 10px 分组标签（剪贴板/字体/段落/样式/审阅），组间 1px 竖线，溢出收进「更多」。避免 35 个控件挤成两三行、高度抖动。
  • Tab 用下划线指示：选中态由「灰底药丸 + 变紫」改为「品牌色文字 + 2px 下划线」，更像编辑器而非导航栏。
  • 顶栏只留全局动作：撤销/重做/查找/外部打开/转 MD/重载/更多 → 30×30 图标按钮；「保存」做成品牌色实心主按钮并带 ⌘S。缩放器移到状态栏（Word 就在那里）。
  • 修订面板改推挤式：从 position:absolute 覆盖正文改为占位 300px 侧栏 —— 现在面板会盖住右半边内容，且用 bottom:28 硬编码对齐状态栏，状态栏一改高度就错位。
  • 标尺校准：现在水平标尺是 repeating-linear-gradient 每 40px 一条线、无刻度数字、从窗口 x=0 起算，而页面正文从画布中心 + 44px 处分栏 —— 完全对不上，且不随缩放变化；竖标尺却是 20px 间隔且随 scale() 缩放。建议统一为「与页面左边缘对齐 + 英寸刻度数字 + 页边距虚线 + 首行缩进手柄」，并随 zoom 联动。
  • 补齐交互态：内联样式写不了伪类，所以现状所有按钮没有 hover / active / focus-visible，disabled 只剩浏览器默认。建议这些 chrome 样式改用 Tailwind class（项目是 Tailwind 4），顺带拿到键盘焦点环。
  • 去硬编码：#e9e9ec / #fff / #b4b4b8 / #0a7d28 / #c0341d / #1a7f37 / #3b6cff（品牌 fallback 与真实 --brand #4b3fe3 不一致）应全部换 Token（--canvas-bg / --success / --danger / --brand）。
  • 消除重复真值：pageStyle 里硬写 794 / 1123 / 96，与 docx-pagination.ts 的 PAGE_W/PAGE_H/PAGE_MARGIN_Y 是两份定义；页眉页脚面板也是 794 固定宽、不随 zoom 缩放。
  • 原生控件：<select> / <input type=number> / <input type=color> 与自绘按钮混搭，风格割裂。建议换成 shadcn 的 Select / Popover + 数值步进器，颜色选择器做成「A + 色条」并弹出调色板。
  • 死 Tab：「引用」整栏 4 个按钮全 disabled「即将支持」；「布局」里放的是表格增删行列（Word 语义下属于表格工具），而真正的页边距 / 纸张方向 / 分栏无处可去。建议要么补上页面设置，要么先把空 Tab 隐藏。
  • 视图一致性：现状「水平标尺不缩放、竖标尺随 scale() 缩放」自相矛盾；建议标尺统一放进画布列（与白纸同为 794px 居中）并随 zoom 重算刻度，竖标尺按 Word 默认收起、在「视图」页提供开关。
