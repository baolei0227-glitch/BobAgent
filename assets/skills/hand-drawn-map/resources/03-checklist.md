# 交付前自检与踩坑对照（L3 按需资源 · QA / 返工标准）

> **用法**：PNG 渲染出来后、向用户汇报之前，按 §1 逐条过一遍；对不上的症状查 §2；判定要不要返工看 §3。
> 本文件是**检查表**，不是规则来源——规则在 `SKILL.md`，技法在 `01-style-library.md`，模板在 `02-composition-templates.md`。

## §1 交付前自检清单（全过才算完成）

### 1.1 内容层 —— 图能不能读

- [ ] 标题 + 副标题一句话说清「主题 + 时间/范围」
- [ ] 有明确起点与终点，读者知道「往哪走」（方向线索：箭头 / 编号递增 / 旗标）
- [ ] 地标 **5–9 个**；每个都有名称；**编号或图标至少有一个**可辨
- [ ] 分区（若有）名称与地标归属一致，不出现「分区里躺着别区的地标」
- [ ] **图例存在**，且覆盖三件事：路径含义 / 分区含义 / 地标类型
- [ ] 真实地理诉求已明确声明局限（本图是「地图风格示意图」，不保证地理准确）

### 1.2 构图层 —— 位置对不对

- [ ] 无重叠：地标↔地标 / 文字↔文字 / 文字↔路径
- [ ] 无出界：全部元素在纸边图框内，四周留边 **≥ 48**
- [ ] 地标之间间距 **≥ 40**
- [ ] **标签不排队**：同一基线附近的相邻文字（尤其「起点/终点」与相邻地标说明）横向间隔 ≥ 60
- [ ] 文字不依赖浏览器换行：长句用 `<tspan x="…" dy="1.5em">` 手动分行，或拆多条 `<text>`
- [ ] 分区带内内容上下留白接近，不出现「上半空着、内容全挤底部」

### 1.3 质感层 —— 像不像手绘

- [ ] 纸底只有 **1 层**（素纸 / 点阵 / 纸纹 三选一，不叠加）
- [ ] 所有描边 `stroke-linecap="round"`；无完美长直线、无硬直角
- [ ] 笔宽只用 3 档（细 / 中 / 粗）；抖动幅度全图一致
- [ ] 手写体只出现在标题 / 区名 / 地标名，且 **≥ 18px**；说明 / 图例 / 注记用系统栈
- [ ] 地标图标已按 `translate(-12*s,-12*s) scale(s)` 居中，无肉眼可见偏心
- [ ] 图标在底盘内的占宽约 **40–50%**（既不满溢，也不缩成一点）
- [ ] 同类图标彼此可区分（桥 ≠ 山洞、塔 ≠ 房子、云 ≠ 山洞）

### 1.4 视觉纪律层 —— 品牌红线

- [ ] 主色 = `#4b3fe3`（深色环境 `#6054f1`）；**主色面积 ≤ 20%**
- [ ] 普通地标用墨色描边；**焦点地标 ≤ 2 个**才用主色
- [ ] 无渐变、无纯黑底、无第三色相；语义色（绿/红/橙）仅用于真实状态
- [ ] 每个 `fill` / `stroke` 显式写 hex，不用 CSS 变量

### 1.5 交付层

- [ ] `homework/` 下**只有** `<主题>-map.png` + `<主题>-map.svg` 两份
- [ ] PNG **不透明**（纸底色已进 PNG，不是透明底）
- [ ] 中间壳 `homework/.ai-workspace/map-render.html` 已删除
- [ ] 汇报含：尺寸 / 构图模板 / 地标数量 / 文件绝对路径

## §2 高频踩坑对照表（症状 → 根因 → 修法）

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | 图标整体偏右下，且缩放越大偏得越多 | 用了 `translate(-12,-12) scale(s)` | 改 **`translate(-12*s,-12*s) scale(s)`**：`s=1.5 → (-18,-18)`、`s=1.7 → (-20.4,-20.4)`、`s=1.9 → (-22.8,-22.8)` |
| 2 | 图标在底盘里「沉底」 | 内容 bbox 中心不在 24×24 正中（树干偏下、宝箱/云整体偏下） | ty 按 bbox 微调（`s=1.5` 基准）：树 `-19.5`、宝箱 `-21`、云 `-21`、桥 `-18` |
| 3 | 图标在底盘里太小 | 直接抄了 24×24 的 `scale(1)` | 普通地标 `rx46 ry34` + `s=1.5`；焦点地标 `rx52 ry38` + `s=1.7–1.9` |
| 4 | 桥和山洞长得像（都成了圆顶） | 桥用单弧+底线被读成洞口；山洞用大圆丘被读成桥 | 桥＝**直线桥面**`<line y1=7 y2=7>` + **大拱**`M3 17 A9 9 0 0 1 21 17`；山洞＝**圆丘**`M2 21 Q12 3 22 21` + **小洞口**`M8.5 21 A3.5 3.5 0 0 1 15.5 21` |
| 5 | PNG 透明底 | HTML 壳 `body` 没给背景 | 壳里 `body{background:#FAF7F2}`，并在 SVG 首位补全幅 `<rect fill="#FAF7F2">` 兜底 |
| 6 | 「起点」和相邻地标的说明排成一行，读成一串连读文字 | 起点/终点标签基线与「上方」地标说明同为 `y=500` | 起点/终点标签下移到道路下方 **`y=620`**，字号 18 |
| 7 | 图看起来像「看板」不像「地图」 | 街区画成规整圆角卡片阵列 | 补道路 / 地标建筑图标 / 图例 / 指北针；打散网格、加微旋转 |
| 8 | 手绘感时有时无 | 抖动幅度 / 笔宽 / 圆头混用 | 全图统一：同一抖动幅度、同 3 档笔宽、全 `round`、同圆头 |
| 9 | 分区带大片空白，像没画完 | 内容基线离带顶过远，上下留白失衡 | 把内容带整体上移，或压低分区带高度，使上下留白接近（差 ≤ 60） |
| 10 | 文字溢出被截断 | 依赖浏览器自动换行（SVG 不换行） | 手动 `<tspan x="…" dy="1.5em">`，或拆多条 `<text>` |
| 11 | 标题没变成手写体 | 字体栈不完整或顺序错 | 标题/地标名用 `font-family="'Kaiti SC','STKaiti',cursive"`；说明文字别用 |
| 12 | 节点挤成一团、线互相穿过 | 节点数 > 20，超出可读上限 | 分区 / 拆多图，或改走 `bob-ui` 的 `widget:mermaid` |
| 13 | 渲染报 `CVDisplayLinkCreateWithCGDisplay failed` / `task_policy_set … invalid argument` | macOS 无头模式已知无害告警 | **不用处理**：`exit code = 0` 且 PNG 正常写出即通过 |

## §3 返工判定标准

### 一票否决（必须返工，不能交付）

- 元素重叠 / 出界 / 文字被截断
- PNG 透明底，或产物缺 PNG / SVG 任一
- **图例缺失**
- 出现渐变或第三色相；主色面积明显 > 20%（一眼看去整图是紫的）
- 真实地理诉求未声明局限

### 建议返工（能改就改）

- 图标偏心 > 2px，或同类图标语义雷同（桥/山洞分不出）
- 起点终点没有方向线索
- 分区带留白失衡（上下差 > 60）
- 手写体误用到说明文字、或字号 < 18px

### 可接受交付（不必返工）

- 装饰件只有 2 件（规则下限就是 2 件）
- T1 / T4 没有比例尺（比例尺是可选装饰）
- 分区带轻微不平衡（上下差 ≤ 60）
