# xhs-rewrite — 小红书风格改写

## 用途

将已有内容改写成**小红书知识卡片风格**的中文文案，用于在 BobWork 中生成 3:4 竖版分享卡（Share → 3:4 post card），或直接输出可发布的文案 / .md 文档。

## 触发方式

用户明确要求改写为小红书风格时启用（如"把这段改写成小红书风格""做成小红书文案"）。不要主动改写普通内容。

## 输出形态（按用户要求二选一）

1. **聊天正文输出**（默认）：直接在回复中给出改写后的完整文案，结构清晰，便于复制进分享卡。
2. **.md 文档输出**：用户要求"写成文档/.md"时，用 write_file 落盘为 markdown 文件：
   - 文件名：`XHS-{主题关键词}-{YYYYMMDD}.md`（如 `XHS-合同风险-20260829.md`）
   - 存放位置：优先当前项目 `homework/` 下；无项目时询问或放应用根目录
   - 文档结构：`# 标题` → 引言钩子 → `## 正文`（分段 + 要点）→ `## 标签`（一行一个）

## 文案结构规范

- **标题**：≤ 20 字，从下方「标题公式库」中选 2-3 个候选套用，挑最有钩子的一个（提问式/痛点式/结论式），如"这份合同的主要风险是什么？""付款条款怎么签才不踩坑？"
- **引言**：1-2 句口语化开场，拉近距离，点明"对谁有用"
- **正文**：
  - 口语化、亲切、段落短（每段 1-3 行）
  - 要点分条，可用 ①②③ 或 1. 2. 3.，每条一句核心
  - 重点可用加粗强调
- **标签**：3-5 个主题标签，**不带 # 前缀**（BobWork 卡片标签样式约定），如 `合同　避坑指南　建议收藏`

## 标题公式库（输出前必须从中选）

| 公式 | 模板 | 法律场景示例 |
|---|---|---|
| 提问式 | 为什么 X？/ X 怎么 X？ | 为什么付款条款总被人钻空子？ |
| 痛点式 | 还在 X 踩坑？/ 别再 X 了 | 还在为合同风险踩坑？ |
| 结论式 | 直接给结论（X 条/1 个） | 劳动合同这 3 条必须改 |
| 数字式 | 数字 + 名词 | 劳动合同 3 个必改条款 |
| 发现式 | 我才发现 / 原来 X | 才发现借款合同要这么签才安全 |
| 反常识式 | 其实 X 不一定 Y | 其实仲裁时效不是你想的 2 年 |
| 身份共鸣 | 给 X 的你 | 给独自创业的你：5 条避坑合同 |
| 悬念式 | X 的秘密 / 法官不会说 | 法官不会明说的举证小细节 |
| 对比式 | 别 X，要 Y | 别急着签字，先看清这 3 条 |
| 热点词 | 新规/热点 + 实用点 | 新公司法下股东最容易忽略的 3 个责任 |

规则：先看内容适合哪个公式，生成 2-3 个候选，选最短、最具体、不夸大的一个。法律场景禁用恐吓式（"不学就完了"）。

## 发布前自检清单（改写完成后逐项自查，全部通过再输出）

1. **事实核验**：金额、日期、期限、法条依据、结论与原文完全一致，无增删、无夸大
2. **合规用词**：无绝对化/极限词（最、第一、唯一、国家级）；无"必看""赶紧""错过后悔"等制造焦虑的营销语；法律建议保留"具体以合同约定/专业意见为准"的稳妥措辞
3. **AI 味检测**：
   - 删掉"首先/其次/最后""总而言之""值得注意的是""总的来说"等模板连接词
   - 删掉"希望能帮到你""希望对你有用"等客套收尾
   - 不堆砌 emoji 图标（默认不加）
   - 读一遍像人话，像专业人士在分享，不像 AI 套模板
4. **格式检查**：标题 ≤ 20 字且套用了公式；每段 ≤ 3 行；要点编号清晰；标签 3-5 个且不带 #
5. **完整性**：原文结构化要点（风险清单、建议清单）全部保留，一条不丢

## emoji 开关

- **默认不加 emoji**（产品偏好克制风格）
- 仅当用户明确要求"加 emoji / 活泼一点"时才适度使用（每段 ≤1 个，不堆砌）

## 专业/法律场景的严谨性约束（重要）

- **保留事实、数字、条款原意**：只调整表达方式，不改变结论、金额、期限、法条依据
- 不夸大、不制造焦虑式营销用语（如"必看""赶紧""错过后悔"）
- 法律建议类内容保留"具体以合同约定/专业意见为准"的稳妥措辞
- 原始内容若有结构化要点（风险清单、建议清单），改写后必须完整保留，不丢项

## 与 BobWork 分享卡衔接

改写后的内容天然适配 BobWork 的 3:4 分享卡：
- 标题 → 卡片大标题；正文要点 → 卡片编号要点/正文；标签 → 卡片标签栏
- 用户可说"把改写结果做成小红书卡片"，随后通过节点的 Share → 3:4 post card 生成图片
