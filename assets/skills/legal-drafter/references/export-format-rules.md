# 下载与导出格式规范

## 自动生成规则

- 生成文书正文后，应自动生成正式文件并通过 `present_files` 工具呈现给用户；不需要用户额外提出"下载、导出、保存、生成文件"等要求。
- 文书正文直接写入生成文件，不在对话中输出代码块预览。

## 格式选择

- 如用户明确指定格式，按用户指定格式生成：Word、Markdown、PDF 或飞书文档。
- 如用户未指定格式，默认同时生成 Markdown `.md` 和 Word `.docx` 两个文件；如用户随后要求 PDF 或飞书文档，再生成对应格式。
- `.md` 文件用于快速预览和二次编辑，`.docx` 文件用于正式交付。

## Markdown `.md` 生成

- 将文书正文按 Markdown 语法写入 `.md` 文件。
- 禁止使用 `---` 水平分割线；条款之间以编号（第一条、第二条等）和空行自然分隔，章节之间以标题（`##`、`###`）分隔。
- 落款使用右对齐 HTML 标签或空格缩进实现。

## Word `.docx` 生成

- 默认使用 `chinese-docx-generator` skill 将文书正文转为 Markdown 后生成 `.docx` 文件。
- 如文书需要复杂排版（图片、脚注、修订追踪等），改用 `minimax-docx` skill。
- 排版格式标准：
  - 页面：A4，页边距 2.54cm。
  - 标题：黑体，H1 居中二号（22pt），H2 三号（16pt），H3 四号（14pt）。
  - 正文：仿宋小四号（12pt），行间距 1.5 倍，首行缩进 2 字符。
  - 落款：右对齐。
  - 表格：网格样式，表头蓝灰色底纹，五号（10.5pt）。

## PDF 生成

- 从已生成的 `.docx` 文件转换为 `.pdf` 文件。

## 飞书文档生成

- 使用 `lark-doc` skill 创建飞书文档。
- 仅在当前环境已连接并授权飞书连接器时直接创建；如不可用，先生成 Word `.docx` 文件，并简要提示飞书文档需连接/授权后才能创建。

## 文件命名与存储

- 文件命名规则：`{文书类型}_{当事人简称或关键词}_{YYYYMMDD}`，扩展名根据格式而定（如 `起诉状_张三诉李四_20260625.md`、`起诉状_张三诉李四_20260625.docx`）。
- 生成的文件应存放于当前工作目录下。

## 交付规则

- 文件创建完成后，通过 `present_files` 工具呈现文件，确保用户可直接查看和下载。
- 如文件生成失败，应明确说明失败原因并给出下一步处理方式。
- 导出文件内容应保持正式、干净，不添加水印，不添加与正文无关的解释、目录、调试信息或内部处理说明。
