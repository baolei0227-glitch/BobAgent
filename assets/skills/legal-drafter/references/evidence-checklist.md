# 证据与事实审查清单

起草诉讼文书或法律意见书时，应主动帮助用户建立证据结构。

## 证据分类

| 类别 | 常见证据 |
| --- | --- |
| 合同关系 | 合同、订单、确认单、聊天记录、邮件、发票、收据 |
| 履行事实 | 交付记录、验收记录、物流记录、银行流水、转账凭证 |
| 违约事实 | 催告记录、拒绝履行证据、质量问题照片、第三方检测报告 |
| 损失金额 | 付款凭证、损失清单、维修报价、评估报告、利息计算 |
| 主体信息 | 身份证、营业执照、法定代表人信息、授权委托书 |

## 缺失证据应对

如用户材料不足，应说明缺失证据对文书的影响，并建议补充方式。
