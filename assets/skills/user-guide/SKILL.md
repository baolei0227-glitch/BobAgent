# BobWork 用户说明书

> 面向普通用户的使用指南。当用户问到「怎么用」「这个功能是什么」「怎么设置」等问题时，参考本文档回答。
> 回答时用通俗语言，避免技术术语，必要时举例说明。

---

## 一、BobWork 是什么

BobWork 是一个运行在你电脑上的 AI 知识画布桌面应用。

它的核心概念是**无限画布 + AI 对话节点**：你可以在一个可以无限缩放、平移的画布上创建 AI 对话节点，每个节点是一个独立的 AI 对话。节点之间可以用线条连接，形成知识图谱——上游节点的总结会自动注入到下游节点的上下文中。

和普通聊天应用最大的区别是：
- **画布式组织**：不是线性聊天列表，而是可视化的节点网络，拖拽连线就能建立知识关系
- **本地存储**：所有数据存在你自己的电脑上（`~/BobWork/`），不经过第三方服务器
- **多项目支持**：可以创建多个项目，每个项目有独立的节点、文件、日历、数据库和工作流模板
- **每个节点独立配置**：不同节点可以选不同的 AI 模型、不同的思考深度、不同的技能
- **工作流模板**：把项目保存为模板，新建项目时一键套用节点配置
- **AI Coding 节点**：可绑定本地小程序项目，在节点里让 AI 直接写代码、跑预览，开发小程序网页
- **子节点网络**：复杂任务可拆成多个子节点并行处理——从节点底部手柄拖出子节点，或框选节点批量生成汇总节点；父子连线前先锁定上游成果块
- **WANTED 指令系统**：在画布浮球输入框用 `/chat` `/todo` `/note` `/help` 快速操作，无需打开节点
- **通知中心（BobMail）**：收件箱式管理 AI 对话邮件 + 即时 Toast 浮层回执
- **微信桥**：微信端发送指令 / 图片 / 语音 / 文件，与桌面画布实时同步

### 核心工作流

1. 在画布上双击创建普通 Chat 节点；右键弹菜单选 AI Coding 节点
2. 在节点里和 AI 对话，流式查看回复（AI Coding 节点会自动把代码写入小程序，可打开预览）
3. 把相关节点连起来，形成知识网络
4. 复杂任务拆成子节点并行处理：从节点底部手柄拖出子节点，或框选节点批量创建汇总节点
5. 下游节点自动获取上游节点的摘要作为上下文
6. 把成熟的工作流保存为模板，下次直接套用

## 二、开始使用

### 首次打开

1. 打开 BobWork 后，如果没有项目，会显示欢迎引导页面
2. 输入项目名称，可选择项目分类（诉讼 / 常法 / 非诉 / 破产），点击创建
3. 项目创建后进入画布主界面（初始节点固定在画布左上角）
4. 点击左下角齿轮图标进入设置，配置 AI 模型供应商

### 配置 AI 模型

BobWork 支持 8 个模型供应商：

| 供应商 | 说明 |
|--------|------|
| DeepSeek | deepseek-chat (V3)、deepseek-reasoner (R1) |
| GLM (智谱) | glm-4-flash、glm-4-plus、glm-z1-flash、glm-4v（视觉） |
| Moonshot | kimi-k2-thinking、moonshot-v1-8k |
| Qwen (通义千问) | qwen-max、qwen-vl-max、qwen3.5 系列 omni/vision/cor 视觉 |
| OpenAI | gpt-4o (多模态)、gpt-4o-mini |
| Doubao (豆包) | doubao-1.5-vision-pro-32k |
| SiliconFlow | 硅基流动开放平台，提供多种开源模型 |
| AgentPlan & CodingPlan | 订阅制专属模型：AgentPlan 负责通用对话与推理，CodingPlan 负责编程任务 |

设置步骤：
1. 点击设置 → 选择一个供应商
2. 填入 API Key
3. 点击"获取模型"自动拉取可用模型列表（**默认全不勾选，避免勾选无关模型**）
4. 勾选要启用的模型；也可点击 **Clear All**（当前厂商）一次性清空后再重选
5. 可展开查看每个模型的详细规格（能力、优缺点、价格、上下文窗口）

> **千问视觉提示**：qwen3.5 系列（omni / vision / cor 等）会自动识别为视觉模型，无需手动切换。

### 模型角色

- **主对话模型（Chat Model）**：设置 → Role Assignment → Chat Model，作为 Auto 模式下默认首选的聊天模型
- **聊天模型**：主力模型，负责每个节点里的对话。每个节点可以独立选择
- **视觉模型**（可选）：当聊天模型不支持图片时，用多模态模型先把图片转成文字描述
- **辅助视觉模型**（可选）：主视觉不可用时的备份
- **任务总结模型**（可选）：WANTED 面板中用来将自由文本总结为结构化任务
- **成果块编辑模型**（可选）：用于结构化编辑文档成果块
- **STT 语音转文字**：设置 → Audio STT Model，支持多厂商（Doubao/DashScope/SiliconFlow/OpenAI）云端转写

每个节点左上角有模型选择器，可以临时切换当前节点的模型。节点头部有思考深度选择器（低/中/高三级，由模型能力自动决定）。

## 三、画布操作

### 画布基本操作

- **平移画布**：在节点外空白区域，按住鼠标左键拖动
- **缩放画布**：鼠标滚轮，或右下角 +/- 按钮
- **创建 Chat 节点**：**双击画布空白处**
- **创建 AI Coding 节点**：**右键画布空白** → 弹出菜单，选「AI Coding 节点」
- **连接节点**：从一个节点的底部手柄拖到另一个节点的顶部手柄
- **框选多个节点**：在画布空白区按住鼠标拖出矩形虚线框
- **批量创建汇总节点**：框选 2 个及以上节点后，虚线框右侧出现 "+ Create Node" 按钮
- **画布外观**：画布带淡淡紫色侵染效果（浅紫底色 + 右上角品牌紫光晕），节点与连线保持清晰；新建项目时初始节点固定在画布左上角，不再居中到可视区中央

### 画布链导航圆点

画布左侧有竖排链导航圆点，基于**主节点（无父节点的根节点）**自动划分独立链。每个圆点对应一条链：
- 点击圆点 → 画布居中定位到该链的第一个节点
- 当前活跃链的圆点高亮显示
- 子节点自动归属到其根节点（主节点）所在的链

### Chat 节点 vs AI Coding 节点（视觉区分）

| | Chat 节点（普通对话） | AI Coding 节点（写小程序） |
|---|---|---|
| 图标 | 南瓜 confused.png（可爱问号脸） | 南瓜 06-万圣节酷酷.png（戴墨镜酷脸） |
| 边框光晕 | 默认暖棕，选中态暖橙发光 | 默认蓝色，选中态蓝色发光 |
| 呼吸灯 | 青色脉冲（执行中） | **蓝色脉冲**（执行中） |
| 标题栏图标呼吸灯 | 节点执行中 1.5s 透明度脉动 | 节点执行中 1.5s 透明度脉动 |
| 系统提示 | 通用提示（节点驱动） | 通用提示 + AI Coding 编程任务上下文 |
| 顶部 | 模型选择器 + 思考深度 | 多：Coding 徽标、Play 预览按钮、输入框 placeholder 定制 |
| 标题 | 普通对话节点名 | 默认 = 绑定的小程序名 |
| 创建方式 | 双击空白、底部手柄拖出 | 右键空白弹菜单 |

### 子节点（并行处理）

子节点 = 用户通过画布 UI 创建的**真实节点**，用于把复杂任务拆解成多个部分处理。AI 不会自动创建子节点，创建权在用户。

**创建方式**：
- **底部手柄拖出**：从节点底部圆形手柄拖出，可新建子节点并联线
- **拖线连接**：从节点底部圆形手柄拖到另一个节点的顶部手柄，建立父子关系
- **批量汇总**：框选 2 个及以上节点后，虚线框右侧出现 "+ Create Node"，一键生成汇总节点

**要点**：
- 建立父子连线前，必须先锁定上游成果块（防止上游改动导致下游结果失效），锁定失败会取消创建
- 子节点自动排列在父节点右侧：1 个平行对齐，2 个以上纵向排列，父节点始终居中
- 子节点自动归属到其根节点所在的链，画布左侧链导航圆点按链定位
- 每个子节点都是独立的 AI 对话，可继续提问、继续创建下游

### 节点内部浏览

- **缩放节点/画布**：按住 ⌘ (macOS) 或 Ctrl (Windows/Linux) + 鼠标滚轮
- **滚动节点内容**：直接在节点区域滚动滚轮
- **平移画布**：左键在节点外空白区拖动

### 节点关系

- **并列 (sibling)**：平行连接，相邻关系
- **子节点 (child)**：上下连接，建立前必须先锁定上游成果块

### 节点管理

- 每个节点右上角有关闭按钮，点击删除节点
- 节点标题可自动生成（AI 建议标题时自动更新）
- 选中节点后按 Delete/Backspace 可删除节点

### Node Map（节点地图 / 全局导航）

画布左下或侧边栏 Node Map 图标打开：
- 标题栏文字已**改为图标**，鼠标悬停显示 "Node Map" tooltip
- 点击未聚焦的节点块 → 自动选中、展开容器、画布居中对齐；再点同一块 → 恢复原视口

### 便签（Sticky Notes）

画布上的即时便签层，随手记录清单或笔记。

- **创建**：右键画布空白 → 菜单选「Sticky Note」→ 弹出选择器二选一：
  - **TODO（勾选清单）**：默认**绿色**便签，每行前有勾选框，勾选完成的条目自动沉到该便签底部
  - **NOTE（编号笔记）**：默认**黄色**便签，每行自动编号 `1.` `2.` `3.`…，适合流水记录
- **标签徽标**：每个便签标题栏左侧固定显示 **TODO** / **NOTE** 徽标（深绿 / 深橙），一眼区分类型
- **创建后不可切换类型**：类型在创建时确定，建好后固定不可改；如需换类型，删除重建即可
- **标题重命名**：**双击便签标题**进入编辑，Enter / 点击别处提交，Esc 取消
- **多分页**：点击标题栏左侧分页按钮展开分页列表，可新增 / 切换 / 重命名分页（每页独立内容）
- **与 /inspect 的关系**：只有 **TODO** 便签会进入待办索引参与 `/inspect` 待办查询，NOTE 便签不会被当作待办

## 四、在节点中对话

### 基本操作

- **发送消息**：在输入框输入文字，按 Enter 发送
- **换行**：Shift + Enter
- **停止回复**：AI 回复过程中点击停止按钮
- **复制消息**：鼠标悬停在用户消息上显示复制按钮

### 模型选择

每个节点顶部有模型下拉菜单，按供应商分组显示已启用的模型。支持"自动模式"——AI 根据任务类型自动选择最合适的模型（若设置过 Chat Model，Auto 会优先用它）。

### 思考深度

节点标题栏有思考深度选择器，支持三级（Low / Medium / High），对应 L / M / H 徽标：
- **Low**：简要思考，快速响应，适合简单问答
- **Medium**（默认）：充分推理，平衡速度与深度
- **High**：深度分析，适合复杂推理和长文档

Auto 模式下由模型能力自主决定思考深度。思考过程默认折叠显示为「💭 Think」芯片，点击可展开查看。**思考深度不再提供"关闭"选项**——所有模型均透明展示思考过程。

### 技能（Skills）

每个节点可以独立选择要启用的技能：
- 点击节点底部的技能按钮，从下拉菜单勾选
- 已选技能显示为可移除的标签
- 在输入框输入 `/` 可以快速调出技能菜单
- 技能管理器（侧边栏底部按钮打开）：按分类显示所有已安装技能

### 附件（本地文件/复制粘贴上传）

- 点击回形针按钮上传文件，或直接粘贴、拖拽文件到输入框
- 支持的格式：图片、文本文件、PDF
- 附件预览显示在输入框上方（棕色系标签），发送前可移除
- **多文件处理**：一次可发送多张图片/多个附件，AI 会在节点内逐一读取处理；需要并行时用子节点手动拆分

### @ 文件引用（materials 素材库引用）

在输入框输入 `@` 会弹出该项目 `materials/` 文件夹中的文件列表：
- 支持子目录递归遍历
- 键盘方向键 ↑↓ 选择，Enter 确认，Esc 取消
- 选中的文件显示为蓝色系标签（@ 图标），与附件标签区分

### 附件 vs @ 引用的区别

| | 附件 | @ 引用 |
|---|---|---|
| 来源 | 任意本地文件 | 仅限项目 materials/ 文件夹 |
| 标签色 | 棕色系（回形针图标） | 蓝色系（@ 图标） |
| 适合场景 | 临时上传单份文件 | 长期参考资料，反复引用 |

### AI Coding 节点（编程模式）

AI Coding 节点 = 普通 Chat 节点 + **绑定了一个本地小程序项目**。

**创建/绑定**：
- 右键画布空白 → AI Coding 节点 → 弹窗选择"新建小程序项目"或"绑定已有项目"
- 创建后会打开 iframe 预览

**首轮交互**：
- 首次对话时，AI 会弹出 **Spec 采集表单**（6 个问题）：功能分类、目标场景、交互呈现、持久化需求、视觉风格、AI 能力接入
- 填写后 AI 根据答案生成代码，确保一次到位

**小程序模板**（11 个场景化模板）：
空白、计算器、待办、习惯追踪、番茄钟、联系表单、数据表格、作品集、落地页、阅读器、格式转换器

**节点能力**：
- 顶部 Play 按钮：强制刷新 iframe 预览
- AI 写代码时：先读 `index.html`、再改、然后截图自检
- 小程序存储位置：`~/BobWork/.sandbox/apps/<appId>/`
- 通过 BobStorage API 支持三层存储：localStorage（自动隔离）、磁盘私有目录、全局 wanted/

**预览**：右侧 Sandbox tab 中 iframe 实时预览，AI 修改后自动刷新。

### 工具调用与步骤看板

AI 在执行操作时会显示结构化步骤卡片：
- 左侧状态色条：成功绿 / 失败红 / 运行中蓝
- 元信息条：工具名、阶段、字符数、复制按钮
- 超长结果（>300字符）默认折叠，点击 "Show more" 展开
- 步骤全部完成且主消息流式结束后，看板自动折叠

### 问答弹窗

AI 回复中可能嵌入问题列表，系统自动提取为弹窗：选择题和自定义回答，提交后自动作为追问发送。弹窗点击外部空白不会自动关闭，需显式操作。

### 心情（Mood）

AI 回复后会在节点中显示心情数据：Vibe、Sparks、Reflections、Will 四个维度。

## 五、WANTED 指令系统

画布右下角的通缉令浮球（WANTED）是快速指令入口。关闭按钮为**通缉令印章风格**（虚线圆环 + 加粗 X + 微倾斜）。

### 可用指令

| 指令 | 功能 | 说明 |
|------|------|------|
| `/chat` | 进入对话模式 | 后续输入直接发给临时 AI 节点；`/chat out` 退出；`/chat new` 开新线程 |
| `/todo` | 添加待办 | 文本消息自动解析为结构化任务，写入日历 |
| `/note` | 记录笔记 | 文本消息归档为笔记 |
| `/help` | 查看帮助 | 显示可用指令列表 |

> 纯文本自然语言消息（无 `/` 前缀）会自动分流：含时间意图 → `/todo` 归纳，无时间 → `/note` 归档。

> `/schedule` 指令已删除，日程查询请直接在对话中提问。

### Toast 即时通知

指令执行后弹出右上角浮层回执（task/note/info/chat 类型），3.5 秒自动消失，**不进收件箱不落数据库**。每种类型有专用 icon + 胶囊标签 + 标题 + 摘要。

## 六、工作流模板

工作流模板用于保存、复用一整套节点配置（标题、模型、技能、默认 Prompt、思考深度等）。

> 旧版本的 5 类预设场景已全部移除，现在模板分类全部通过自定义输入填写。

### 把项目保存为模板

在侧边栏项目列表中，hover 项目行右侧显示竖排三个点（⋮）菜单，点击展开全部项目操作：

1. **Expand / Collapse file tree** — 展开/收起项目文件树
2. **Open in Finder** — 在系统文件夹中打开项目目录（桌面端）
3. **Save as Template** — 保存为工作流模板
4. **Edit category & tags** — 编辑项目分类与标签
5. **Refresh file list** — 刷新文件树（仅文件树展开时显示）
6. **Archive project** — 归档项目
7. **Delete project** — 删除项目（移入垃圾桶）

### 模板管理

侧边栏 **Bob Items** 面板（默认折叠，点击标题栏展开）：
- 显示模板名称、步骤数、分类
- ▶️ Apply 按钮一键创建模板节点到画布
- 🗑️ Delete 按钮（两次点击确认）

## 七、侧边栏

### 布局结构

展开态从上到下：

1. **系统图标行**：Logo（点击打开设置） + Calendar（日历） + BobMail（通知中心）
2. **标题行**：BobWork + 版本号
3. **Workspace**（项目分组，可折叠，点击标题行展开/收起，默认展开）
4. **Bob Items**（模板面板，默认折叠）
5. **Sandbox Panel**（默认折叠）
6. **WANTED 任务面板**（默认折叠）

## 十二、数据存储与安全

### 隐藏文件夹方案

所有 BobWork 内部路径统一加 `.` 前缀（隐藏）：
```
.project.db  .templates.db  .sandbox/  .logs/
```

### 存储位置

```
~/BobWork/
├── .settings.json        # 全局设置
├── .projects.json        # 项目列表
├── .templates.db         # 模板数据库（全局）
├── avatars/              # 自定义头像
├── projects/<id>/
│   ├── .project.db       # SQLite
│   ├── nodes/            # 节点 .md 文件
│   ├── materials/        # @引用素材
│   └── homework/         # 法律/作业场景
└── .sandbox/apps/<id>/   # 小程序
```

### 智能扩展名补充

AI 生成的文件无扩展名时，系统根据内容特征自动推断并补充 `.html` `.md` `.json` 等后缀，避免产生无法预览的"僵尸文件"。

### 本地文件授权

只限制 AI，不限制用户本人：
- 你可以在侧边栏浏览本机任意目录
- AI 只能读取沙箱目录 + 你主动授权的外部目录
- 尝试访问未授权目录返回 403 并提示可授权路径

## 十五、Bob Browser 网页自动化

Bob Browser 是内置的浏览器自动化能力：AI 可以**直接操作你正在使用的 Chrome 标签页**完成网页操作（填表、点击、导航、抓取、下载等），复用你的登录会话，全程实时可见。

### 典型用法

在对话里直接描述目标即可，例如：
- 「帮我在公司立项系统填立项申请表，项目名称 XX、预算 XX」
- 「打开某法院网站，检索 XX 案件的公告」
- 「把当前页面的表格内容提取出来」

### 网页填表流程

AI 自动按以下链路完成，**不需要你预先手动操作一遍**：

1. **定位**：`browser.snapshot` 抓取页面交互元素清单（带稳定引用，如 e5）
2. **填充**：`browser.fill_form` 一次填多个字段 / `browser.type` 填单个输入框 / `browser.select_option` 选下拉
3. **提交**：`browser.submit` 提交表单
4. **验证**：`browser.screenshot` 截图给你确认

### 需要你配合的场景

| 场景 | 处理方式 |
|---|---|
| 登录态 | 保持网站已登录，AI 复用你的会话；过期时你手动登录一次即可 |
| 上传附件 | AI 选本地文件，或你手动选一次 |
| 验证码 / 短信校验 | 必须你手动完成，AI 等校验通过后继续 |
| 需人工判断的字段 | 你口述内容，AI 填入 |
| 不可逆提交（审批/付款） | 建议最后一步提交由你手动点，AI 负责填满表单 |

### 复杂页面定位

动态页面/特殊控件定位不到时，AI 会请求你**在页面上亲自点击目标元素**（元素 hover 红色高亮），点击后 AI 获得精确位置继续操作。

### 其他能力

- **抓取内容**：提取页面文字 / 结构 / 截图
- **录制回放**：`browser.record` 录制你的操作步骤，之后可自动回放（适合多步向导流程）
- **导航控制**：打开/切换/关闭标签页、前进后退、刷新
- **网络与存储**：读取网络请求、Cookie、本地存储

## 常见问题

### 怎么添加模型？
设置 → Chat Models → 选择供应商 → 输入 API Key → 获取模型 → 勾选启用。可点 Clear All 清空再重选。

### AgentPlan / CodingPlan 是什么？
订阅制专属模型：AgentPlan 负责通用对话与推理，CodingPlan 负责编程任务，通过专属网关接入。

### 思考深度有"关闭"吗？
不再提供关闭选项。所有模型均透明展示思考过程（默认折叠为 Think 芯片），提供 Low / Medium / High 三级强度。

### 小程序模板有哪些？
11 个：空白、计算器、待办、习惯追踪、番茄钟、联系表单、数据表格、作品集、落地页、阅读器、格式转换器。创建 Coding 节点时选择。

### 画布上的竖排圆点是什么？
链导航圆点，基于主节点自动划分独立链。点击圆点居中定位到对应链；蓝色高亮表示当前活跃链。

### 怎么切换项目？
点击侧边栏 **Workspace** 分组中的项目名称即可切换；选中项目自动展开其文件树。

### 项目怎么加分类和标签？
新建项目时弹窗内选择**分类**（诉讼 / 常法 / 非诉 / 破产）；分类和自定义标签（最多 2 个）随时可通过项目行的 ⋮ 菜单 → **Edit category & tags** 修改。分类和标签显示在项目标题右侧。

### 项目误删了怎么恢复？
删除是软删除——项目移入侧边栏底部的 **Trash** 分组，数据保留。展开 Trash 分组即可**恢复**（Restore）或**彻底删除**（Purge）。

### 节点之间怎么连线？
从一个节点的底部圆形手柄拖到另一个节点的顶部手柄。

### 怎么创建子节点？
从节点底部圆形手柄拖到空白处新建子节点，或拖到另一节点的顶部手柄建立父子连线；框选 2 个及以上节点点 "+ Create Node" 批量生成汇总节点。

### 创建子节点为什么要求锁定上游？
建立父子连线前需先锁定上游成果块，防止上游被修改导致下游结论失效。锁定失败会取消创建。

### AI 会自动创建子节点吗？
不会。子节点的创建权在用户（画布 UI 操作），AI 在节点内完成任务。

### BobMail 怎么用？
侧边栏 BobMail 图标打开。INBOX 显示待处理邮件（CHAT 对话 + SCHEDULES 提醒），ARCHIVE 显示已归档。多轮对话折叠显示，点击 Archive 归档整条线程。

### 邮件角标怎么消？
被回复的邮件自动停止角标提示（标记已读）。所有邮件统一通过 Archive 按钮归档。

### WANTED 怎么用？
画布右下角浮球输入指令：`/chat` 对话、`/todo` 待办、`/note` 笔记、`/help` 帮助。返回右上角 Toast 即时回执。

### 微信怎么绑定？
设置 → 微信绑定 → 扫码。支持发送文字/图片/语音/文件，15 分钟去重，90 秒超时保护。

### 怎么把项目保存为模板？
hover 项目行右侧显示 ⋮ 菜单 → **Save as Template**。非当前项目会先自动切换再弹保存框。

### 模板保存在哪里？可以跨项目用吗？
全局 `.templates.db`，跨项目可用。侧边栏 **Bob Items** 面板统一管理。

### 主题有哪些？怎么切换？
统一单一品牌色（Purple，对齐 dynamic-ui 默认紫色主题），App / 小程序 / Widget 同读同一组 Token，无需切换。设置 → Theme 可查看 Token 一览。

### 小程序的配色会跟随主题吗？
会。小程序统一消费宿主注入的 `var(--brand)` / `var(--surface)` 等 CSS 变量，亮/暗（`data-bob-dark`）自动适配。

### 日历可以不填时间吗？
可以。创建事件时不填开始时间即为无时间清单项，显示为全局待办。

### 怎么检查更新？
侧边栏底部刷新按钮，或启动时自动检查。下载成功后齿轮旁出现橙色 Install 按钮。

### 数据存在哪里？
`~/BobWork/` 目录，全部本地存储。
