# BobWork 用户说明书

> 面向普通用户的使用指南。当用户问到「怎么用」「这个功能是什么」「怎么设置」等问题时，参考本文档回答。
> 回答时用通俗语言，避免技术术语，必要时举例说明。

---

## 一、BobWork 是什么

BobWork 是一个运行在你电脑上的 **AI 知识工作台**桌面应用：把 AI 对话、知识笔记、待办日程、文档与小程序的写作产出，按「项目」组织在一起，全部数据保存在本地。

核心概念：

- **项目（Project）**：工作的基本单元，例如一个案子、一个客户或一个主题。每个项目有独立的 AI 会话、文件、日历事件、笔记与便签。
- **会话（Session）**：不同类型的 AI 对话节点（Chat / Coding / Kar / Butler / ImageGen）。每个会话独立配置 AI 模型、思考深度与技能，互不干扰。
- **会话关系**：会话之间可建立关系形成「链」；左下角 **Node Map** 用关系图统一查看与管理节点连线，节点执行状态在这里实时可见。
- **本地存储**：所有数据存放在你电脑上（默认 `~/BobWork/`，可用环境变量 `BOBWORK_HOME` 改变），不经过第三方服务器。
- **⌘F 统一面板**：一个快捷键入口承载文件搜索、快捷指令（`/todo` `/note` 等）和全部功能入口，是 BobWork 最主要的快捷操作方式。
- **BobMail 通知中心**：收件箱式管理 AI 对话邮件、日程提醒、巡检/网页报告等。
- **Kar 笔记库**：把随手记录编译成个人知识库（raw → wiki → index 三层），长期沉淀可检索的知识。
- **Bob Sandbox 小程序**：AI Coding 会话直接编写并运行本地小程序（HTML 网页应用）。

### 典型工作流

1. 新建或进入一个项目。
2. 点项目标题旁的 **＋（Add session）** 新建会话：日常提问用 Chat，写小程序用 Coding，整理知识用 Kar，安排日程待办用 Butler，画图用 ImageGen。
3. 在会话里和 AI 对话，流式查看回复。
4. 用 ⌘F 面板发快捷指令（`/todo` 加日程、`/note` 记笔记、`/inspect` 查待办…）。
5. 相关会话在 Node Map 中连成关系图，下游会话自动引用上游的关键成果作为上下文。

## 二、主界面速览

BobWork 的主界面分为几块：

- **左栏（会话导航）**：顶部是全局工具图标，往下是当前项目标题（点击打开 Workspace 浮层，右侧 **＋** 新建会话），再往下是按「链」分组的会话树。底部是 BobWork 版本号按钮（**检查更新**入口）。
- **中栏（主会话区）**：展示当前聚焦的会话；无会话时显示引导提示。点左栏会话行即可切换聚焦。
- **右下（Node Map）**：关系图缩略图入口，展开后可查看会话连线、执行状态并管理关系。
- **Workspace 浮层**：点左栏项目标题打开，管理项目列表与文件树。
- **⌘F 统一面板**：按 `⌘F`（Windows/Linux 为 `Ctrl+F`）打开。
- **右侧面板区**：UnifiedViewer 预览与本地文件浏览。

### 左栏全局工具

| 图标 | 功能 |
|---|---|
| Search（⌘F） | 打开统一面板：搜索文件 / 发快捷指令 |
| Project board | 项目看板（大视图，浏览与切换项目） |
| Bob Sandbox | 打开小程序管理（全屏） |
| Notes | 打开笔记库界面 |
| Calendar | 打开日历 |
| Local files | 打开本地文件浏览/授权 |
| Trash | 回收站（误删的会话节点可恢复） |

### 会话树

左栏中部按「链」列出会话：每条链的根会话是标题行，子会话缩进在下方。行末圆点表示状态：**实心绿点 = 已完成**、**绿色呼吸 = 正在执行**。hover 行尾的 **✕** 可删除该会话（进回收站）。

### ⌘F 统一面板

`⌘F` 打开一个居中的搜索/指令面板：

- **文件搜索**：直接输入文字搜索当前项目文件。
- **指令模式**：输入以 `/` 开头的内容即进入指令模式（见「快捷指令」章节）。
- 底部图标栏是全部功能入口：
  - **Actions**：Settings（设置）、Project board（项目看板）、Extensions Store（扩展/技能商店）
  - **Library**：Bob-Mind、Notes（笔记）、Mini Program Store（小程序）、Agent Teams（团队）、Model Usage（用量）
  - **My Quick**：你自建的快捷入口
  - **Tools**：New project（新建项目）、Templates（docx 字段模板）、Markdown（快速新建会话文档）、Calendar
  - **Starred**：标星的小程序，点击直接预览

## 三、开始使用

### 首次打开

1. 首次打开 BobWork，没有项目时会显示欢迎/新建项目引导，创建第一个项目即可。
2. 项目创建后进入主界面，中栏显示空态引导。
3. 点击左栏项目标题旁的 **＋（Add session）** 新建第一个会话。

### 新建项目与分类

- **新建项目**：⌘F 面板 → Tools → New project；或在 Workspace 浮层中点 New project。
- **项目分类**：创建时可选择（如 诉讼 / 常法 / 非诉 / 破产，可留空），显示在项目名旁。
- **自定义标签**：每个项目可加标签（最多 2 个），便于归类。

### 新建会话（＋Add session）

点左栏项目标题右侧的 **＋**，下拉选择会话类型：

| 类型 | 用途 | 强调色 |
|---|---|---|
| **Chat** | 通用 AI 对话，适合日常问答、分析、写作 | 中性描边 |
| **Coding** | AI 编程会话：绑定一个小程序项目，直接写代码并预览 | 蓝 |
| **Kar** | 个人知识库（笔记）管理，对话即可查笔记、整理素材 | 黄 |
| **Butler** | 待办与日程助理，和便签、日历双向打通 | 绿 |
| **ImageGen** | AI 生图 / 修图工作台 | — |

新建的会话会出现在左栏会话树，并自动聚焦到中栏。

### 配置 AI 模型

BobWork 支持多家模型供应商（共用 OpenAI 兼容接口）：

| 供应商 | 说明 |
|---|---|
| DeepSeek | deepseek-v4-flash（快速）/ deepseek-v4-pro（强推理） |
| GLM（智谱） | glm-5.2 / glm-5-plus / glm-5-air / glm-4 系列，glm-5v 系列视觉，另有 embedding、cogview 生图、cosyvoice 语音等 |
| Moonshot（Kimi） | kimi-k3（支持视觉与思考）、kimi-k2-6 |
| Qwen（通义千问） | qwen-max、qwen-vl-max 视觉 |
| OpenAI | gpt-4o / gpt-4o-mini |
| Doubao（豆包） | doubao-1.5-vision-pro-32k 等 |
| SiliconFlow | 硅基流动开放平台（如 DeepSeek-V3） |
| AgentPlan / CodingPlan | 订阅制专属网关：通用对话推理（AgentPlan）与编程（CodingPlan） |
| Ollama | 本机 Ollama，运行时自动发现本地模型，无需 API Key |
| BobMultimodal | 本地多模态服务（MLX 离线）：视觉 + 语音识别，无需 API Key |

**添加模型（Test & Add 流程）**：设置 → Role Assignment → 顶部 **Model Pool** 按钮打开模型池弹窗：

1. 选择供应商（按区域分组：Mainland China / Volcengine Ark / Others）。
2. Base URL 默认已填好该厂商的地址（可点 Customize 自定义，Reset 还原）。
3. 填入 API Key（本地厂商 Ollama / BobMultimodal 可不填）。
4. 在输入框粘贴/输入模型 ID（例如 `deepseek-v4-flash`），点 **Test & Add**。
5. 连接验证通过后模型自动加入候选池并被勾选；池中模型即出现在所有会话的模型选择器里，也可点 X 移除。

> 本地模型默认不自动发现，需要手动添加。

### 模型角色（Role Assignment）

设置 → Role Assignment 分配各用途的默认模型（从「已加入模型池」的候选中单选/多选）：

- **Chat Model**：对话默认模型（候选池首个即默认）；Auto 模式在此基础上按任务类型每轮挑选
- **Task Model**：任务摘要 / 会议纪要 / 日程解析
- **Outcome Model**：成果块 / 法律引用等结构化编辑
- **Audio STT Model**：语音转文字（支持豆包、AgentPlan/CodingPlan、DashScope、SiliconFlow、OpenAI、本地 BobMultimodal）
- **Image Edit Model**：AI 修图独立于聊天模型，走 images 专用接口

> 视觉识别（图片转文字、OCR）由 Bob OCR 扩展统一管理，不再需要单独配置「视觉模型」角色。

### 设置面板分区一览

按 **⌘F → Actions → Settings** 打开设置面板，左侧分区：

- **Models**：Role Assignment（角色分配）、Model Usage（用量统计）
- **Appearance**：Theme & Appearance（主题与外观）、Icons & Avatars（图标与头像）
- **Prompts**：Quick Prompts（快捷提示词）
- **Extensions**：Templates（docx 字段模板）、WeChat Bind（微信绑定）
- **Agents**：Agents（各 Agent 的自定义提示与启停）
- **Overview**：Architecture（能力架构图）

技能/扩展的安装管理在 **⌘F → Extensions Store**（独立窗口，默认打开市场页，可下载安装技能）。

## 四、在会话中对话

### 基本操作

- **发送消息**：在输入框输入文字，按 Enter 发送
- **换行**：Shift + Enter
- **停止回复**：AI 回复过程中点击停止按钮
- **复制消息**：鼠标悬停在消息上显示复制按钮
- **会话标题**：AI 会根据内容自动生成（也可手动修改）

### 模型选择

每个会话顶部有模型下拉菜单，按供应商分组显示已加入的模型。**Auto 模式**：由 AI 按任务类型在对话模型候选池中自动挑最合适的模型（每轮动态选择，不锁定）。

### 思考深度

会话标题栏有思考深度选择器，三级（L / M / H 徽标）：

- **Low**：简要思考，快速响应，适合简单问答
- **Medium**（默认）：充分推理，平衡速度与深度
- **High**：深度分析，适合复杂推理与长文档

Auto 模式下思考强度默认 **High**（可手动调整）。思考过程默认折叠显示为「💭 Think」芯片，点击可展开查看；不再提供「关闭思考」选项。

### 技能（Skills）

每个会话可独立启用技能：

- 点击输入框上方的技能按钮勾选，已选技能显示为可移除标签
- 在输入框输入 `/` 可快速调出技能菜单
- 未安装的技能需先在 **⌘F → Extensions Store** 下载安装后才可使用

### 附件（本地文件/粘贴上传）

- 点击回形针上传文件，或直接粘贴、拖拽文件到输入框
- 支持格式：图片、文本、PDF、音视频等
- 附件预览显示在输入框上方，发送前可移除
- 一次可发送多个文件，AI 会在会话内逐一读取

### @ 文件引用（materials 素材库）

在输入框输入 `@` 弹出该项目 `materials/` 文件夹中的文件列表，方向键选择、Enter 确认。适合长期参考资料反复引用。

| | 附件 | @ 引用 |
|---|---|---|
| 来源 | 任意本地文件 | 项目 materials/ 文件夹 |
| 适合场景 | 临时上传单份文件 | 长期参考资料反复引用 |

### 工具调用与步骤看板

AI 执行操作（搜索、读写文件、调用扩展等）时会显示结构化步骤卡片：状态色条（成功绿/失败红/运行中蓝）、工具名与字符数、超长结果折叠可展开。

### 问答弹窗

AI 回复中可能嵌入需要你回答的问题，自动弹出选择题/填空，提交后作为追问自动发送。弹窗点外部空白不会自动关闭。

## 五、快捷指令（⌘F / 命令模式）

过去独立的「WANTED 浮球」已并入 **⌘F 统一面板**：打开面板后输入以 `/` 开头的内容即进入指令模式，会弹出候选指令；也可以直接在会话中让 AI 代为执行。

### 可用指令

| 指令 | 功能 | 说明 |
|---|---|---|
| `/todo` | 添加日程事件 | AI 把文本解析成日历事件；`/todo del today/week/日期` 删除；`/todo check today/week/overdue/关键词` 查询日程 |
| `/note` | 记笔记 | AI 编译文本进个人知识库；`/note check` 查询、`/note ingest` 编译积压素材、`/note review` 回看、`/note lint` 自检 |
| `/clip` | 收集素材 | 把原文素材放进收件箱（raw/）暂不编译，之后用 `/note ingest` 统一编译 |
| `/chat` | 临时 AI 对话 | 一条消息发到临时会话，15 分钟无后续自动结束 |
| `/meeting` | 会议纪要 | 开启会议会话，之后的内容累积成一场会议，`/meeting out` 结束并自动生成纪要发到 BobMail |
| `/inspect` | 查待办 | 列出当前项目所有便签里未完成的待办（项目→便签→页）；`/inspect all` 跨全部项目，可带关键词过滤（如 `/inspect 合同 报价`） |
| `/help` | 帮助 | 列出全部指令及用法 |

> 指令后无需空格：`/todo买牛奶` 也可以。
> 纯文本消息**不会**被自动转成待办/笔记——请显式使用 `/todo` 或 `/note`。

### 结果去向

- `/todo`、`/note` 新建内容 → 右上角 **Toast 即时回执**（不进收件箱）。
- `/todo del`、`/todo check`、`/note check`、`/inspect`、会议纪要 → 生成 **BobMail 邮件**。
- `/chat` → 直接进入临时对话。

## 六、BobMail 通知中心

点击左下角 Node Map 角标（或展开 Node Map 后标题栏的 Inbox 按钮）打开。

### 分区与类型

- **INBOX**（待处理，默认展开）
- **ARCHIVE**（已归档，默认折叠）

邮件按类型分为 7 桶：**CHAT**（AI 会话问答）、**SCHEDULES**（日程提醒 / 待办删除/查询 / 日报）、**ACTIONS**（任务/笔记等即时动作）、**WEB**（网页报告）、**INSPECT**（待办巡检报告）、**NOTES**（笔记查询结果）、**MEETINGS**（会议纪要）。

### 已读与角标

- 打开收件箱**不会**自动标已读；点开某封邮件才标记已读。
- 侧边角标数字 = **INBOX 中未归档的邮件数**（含已读未归档）。需要消除角标请归档或删除，而不是只读一遍。
- 被回复的上一轮 Chat 邮件会自动标已读。

### 归档操作（按类型）

- **日程类**（calendar）：行内圆圈「Complete」→ 完成并归档。
- **Chat 对话线程**：行内 Archive 图标，归档整条线程的所有轮次。
- **其它**（web / notes / inspect / 巡检 / 日报等）：行内「Mark as done」单条归档。
- 详情页快捷键：**E** 归档/取消归档、**R** 回复、**S** 星标、**⌘⇧D** 删除。
- ARCHIVE 分区标题栏有 **Select** 按钮，进入多选删除模式。

### 报告邮件（WEB）

网页报告邮件提供两个按钮：**下载 .md**（导出本地）与 **复制链接**。复制出的链接粘贴到任一 AI 对话框后，AI 会自动读取并分析该报告内容。

### 自动送达的邮件

- **Morning Report**：每天上午的日程/待办日报（也推送到微信）。
- **Sticky Report 每日巡检**：汇总全部项目未完成的便签待办。
- **日历到期提醒**：事件到点自动发提醒邮件。
- **笔记维护摘要**：笔记库定期自动 ingest / review 后发摘要。

## 七、便签与待办（Sticky Notes）

便签是快速记待办的轻量清单，依附在**每个 AI 会话的标题栏**（便签图标点开即展开清单卡）：

- **新建**：展开便签卡后点 **＋** 新建，默认创建一张绿色 **TODO** 清单便签。
- **颜色**：绿/蓝/黄/粉可选。
- **完成行自动沉底**：勾选完成的事项移到便签底部。
- **上限**：每个项目最多 3 张待办便签。
- **查询**：便签里未完成的待办会被 `/inspect` 汇总成巡检报告（按 项目→便签→事项 组织）。
- 便签与日历双向联动：便签里的事项可同步成日历事件。

> 旧版「编号笔记（NOTE）」模式已停用；记录长内容请用 `/note` 或 Kar 会话。

---

## 八、日历

- **打开**：左栏 Calendar 图标，或 ⌘F → Tools → Calendar。
- **月视图/日视图**：显示当月事件，可点击切换。
- **创建/编辑事件**：标题、描述、地点、开始/结束时间、全天开关、优先级、颜色、标签与到期提醒。
- **删除**：删除的事件只是隐藏（软删除），不再出现在日历中。
- **导入/导出**：支持 `.ics` 导入导出与订阅（CalDAV / WebCal）。
- **快捷添加**：⌘F 发 `/todo` 让 AI 解析文本并直接写入日历。
- **无时间清单项**：不带具体时间的事项也可入库，显示在日程查询（`/todo check`）与导出中。

## 九、Kar 笔记库（个人知识库）

Kar 会话是你的个人知识库助手（借鉴 Karpathy「LLM Wiki」思路），负责把零散记录编译成可检索、可复用的长期知识：

- **三层结构**：raw（原始素材）→ wiki（编译后的知识条目）→ index（索引）。
- **投喂素材**：⌘F 用 `/clip` 把原文先收进 raw/；用 `/note` 直接让 AI 编译成 wiki。
- **查询/维护**：`/note check` 查询笔记、`/note ingest` 编译积压、`/note review` 定期回看、`/note lint` 质量自检。
- **浏览界面**：左栏 Notes 图标或 ⌘F → Notes 打开笔记库面板，支持全文检索、标签、日期筛选。
- 在对话里直接向 Kar 提问，它会检索笔记回答，避免重复记忆。

## 十、Workspace 与本地文件

### Workspace 浮层

点击左栏顶部当前项目名（或折叠图标旁）打开 Workspace 浮层：

- **Starred**：标星项目置顶分组。
- **当前项目**：点击项目名展开/收起文件树；分类与标签显示在名称旁。
- 项目行操作：标星、Open in Finder（桌面端）。
- **切换项目**：点标题栏的 FolderOpen 图标下拉选择，或在 Project board 中切换。
- 文件树内文件：双击预览（UnifiedViewer），右键更多操作；homework 目录内是 AI 会话产出文件。

### 本地文件与授权

- 你可以在本地文件面板浏览本机任意目录（只限制 AI，不限制你）。
- AI 默认只能读写：当前项目目录、homework 工作区、bob-sandbox 小程序、你主动授权的外部目录、skills 目录。
- 在本地文件面板中可对目录「授权」给 AI 读写；AI 尝试访问未授权目录时会提示并申请授权。

## 十一、AI Coding 会话与小程序

**Coding 会话** = 对话 + 一个本地小程序项目（Bob Sandbox）：

1. 左栏 **＋ → Coding**，在弹出的对话框中给小程序命名、选一个方向/模板（或空白起步），先创建小程序再建立会话。
2. 在会话里描述你想要的页面/功能；AI 首轮会弹出设计表单确认需求，然后直接写代码。
3. 写好的页面可实时预览：⌘F → Mini Program Store / Bob Sandbox，或会话顶部 Play 按钮。
4. AI 修改代码后预览自动刷新；生成结果保存在项目 homework 目录。

**ImageGen 会话**：文生图/图生图工作台。选中会话后下方出现提示条，输入描述生成图片；生成图自动保存到当前项目 homework 目录，可继续在编辑器里区域重绘、AI 修图，并保留版本历史。

## 十二、数据存储与安全

### 数据根目录

默认 `~/BobWork/`（可用环境变量 `BOBWORK_HOME` 覆盖到其它位置）。

```
~/BobWork/
├── .settings.json          # 全局设置（自动滚动备份）
├── .projects.json          # 项目列表
├── .agents.json            # Agent 配置
├── .calendar.db            # 日历（全局）
├── .inbox.db               # 收件箱（BobMail，全局）
├── .usage.db               # 用量统计（全局）
├── BobWorkspace/           # 所有项目
│   └── <名称>-日期/
│       ├── notes-memory/   # 会话笔记（.md）
│       ├── materials/      # @ 引用素材库
│       ├── homework/       # AI 交付/产出（ImageGen 图片、文档等）
│       ├── attachments/    # 对话附件
│       ├── sticky-notes/   # 便签与待办索引
│       └── .project.db     # 项目数据库
├── bob-sandbox/
│   └── apps/<appId>/       # 小程序源码
├── extensions/             # 随包扩展数据
│   ├── bob-notes-mcp/notes # 笔记库（raw/wiki/index，Kar 的底层）
│   └── bob-ocr-mcp/        # OCR 配置与缓存
├── skills/                 # 已下载的技能
├── .bin/  .logs/  .cache/  # 内部二进制/日志/缓存
└── (按需) avatars/ 等
```

- 所有数据都是本地的 SQLite / 文件，卸载前请先自行备份。
- 技能在 **⌘F → Extensions Store** 下载，安装在 `~/BobWork/skills/`。

### 隐私边界

- 微信桥只在本机运行；消息处理有去重与超时保护。
- AI 不能偷偷访问你的隐私目录；要 AI 读写外部目录必须先授权。

## 十三、实用技巧

### 用 ⌘F 快速操作

所有常用功能都能在 ⌘F 面板一步到达：发指令（`/todo`）、搜文件、开设置、开日历、新建项目、打开文档模板。

### 不同会话用不同模型

简单对话用便宜快速模型，复杂推理用强模型；不确定就选 Auto。

### 记录与沉淀

- 随手的事 → `/todo` 进日历；到点自动提醒进 BobMail。
- 想记的长内容 → `/note` 或交给 Kar；长期引用素材 → `/clip` 先收着，攒一批再 `/note ingest`。
- 用便签勾清单，`/inspect` 汇总成巡检报告。

### @ 引用 vs 附件

- 临时文件 → 回形针附件
- 长期资料 → 放 materials/ 目录，用 @ 引用

### 需要固定版式的 Word？

用 **docx 字段模板**：设置 → Extensions → Templates 管理模板库；编辑 Word 时通过预览面板的 Templates tab 选择模板并填入字段。BobWork 只保留这一种「模板」概念（会话模板已移除）。

### HTML 文件怎么快速改文字？

在预览面板打开 HTML 编辑模式 → 点击页面元素弹出工具条：**⚡ 直接替换**（本地秒改、保留加粗斜体，不调 AI）或 **✨ AI 优化**（先生成纯文字草稿，确认后再替换）；`⌘/Ctrl + Enter` 直接应用。

### 网页/报告怎么分析？

BobMail 里打开 WEB 报告邮件 → 点「复制链接」→ 粘贴到任一 AI 对话框，AI 自动读取分析；也可「下载 .md」导出。

### 截图 / OCR？

按 **⌘ + Shift + O**（Windows/Linux 为 Ctrl+Shift+O）进入截图：选区截屏后可裁剪、标注；点「OCR」把截屏区域转成文字，在弹窗中复制使用；✓ 则直接把裁剪图片复制到剪贴板。

## 十四、Bob Browser 网页自动化

Bob Browser 是内置的浏览器自动化能力：AI 可以**直接操作你正在使用的 Chrome 标签页**完成网页操作（填表、点击、导航、抓取、下载等），复用你的登录会话，全程实时可见。

### 典型用法

在对话里直接描述目标即可，例如：
- 「帮我在公司系统填立项申请表，项目名称 XX、预算 XX」
- 「打开某法院网站，检索 XX 案件的公告」
- 「把当前页面的表格内容提取出来」

### 需要你配合的场景

| 场景 | 处理方式 |
|---|---|
| 登录态 | 保持网站已登录，AI 复用你的会话；过期时你手动登录一次 |
| 验证码 / 短信校验 | 必须你手动完成 |
| 不可逆提交（审批/付款） | 最后一步建议由你手动点击 |

## 常见问题

### 怎么添加模型？
设置 → Role Assignment → Model Pool：选供应商、填 API Key、粘贴模型 ID 点 **Test & Add**，验证通过后自动可用。

### 本地模型怎么加？
Ollama 与 BobMultimodal 是本地厂商，无需 API Key（填任意值或留空），直接输入本地模型 ID 测试添加。

### AgentPlan / CodingPlan 是什么？
订阅制专属模型网关：AgentPlan 负责通用对话推理，CodingPlan 负责编程任务。

### 怎么新建会话？
点左栏项目标题旁的 **＋（Add session）**，选 Chat / Coding / Kar / Butler / ImageGen。

### 怎么删除会话？
左栏会话树 hover 该会话，点行尾 ✕（可到 Trash 回收站恢复）。

### 会话执行中怎么看状态？
左栏会话行末绿点：实心=完成、呼吸=执行中；Node Map 中对应节点也有状态提示。

### 怎么查待办？
⌘F 输入 `/inspect`（本项目的便签待办）或 `/inspect all`（全部项目），结果发到 BobMail。

### 怎么加日程？
⌘F 直接发 `/todo 明天下午三点和客户开会`，AI 解析后写入日历；`/todo check` 查询、`/todo del` 删除。

### 怎么记笔记？
⌘F 发 `/note 你的内容` 存入知识库；新建 Kar 会话可持续对话式整理；`/note check` 查询已有笔记。

### 模板（Templates）是什么？Bob Solution 还有吗？
模板仅指 **docx 字段模板**（固定版式、占位字段）：在设置 → Templates 管理，编辑 Word 时经预览面板 Templates tab 套用。原先的会话模板（Bob Solution）已移除，不再提供保存/套用整套会话的功能。

### 模型在哪里管理？
所有模型都进「模型池」（设置 → Model Pool），勾选后才会出现在会话选择器里。

### 思考深度可以关吗？
不能关闭。三级强度 Low / Medium / High，思考过程透明展示（默认折叠为 Think 芯片）。

### 便签建在哪里？有什么限制？
便签依附在每个 AI 会话标题栏（便签图标展开 → ＋ 新建），默认绿色 TODO 清单，每个项目最多 3 张。

### 数据和笔记存在哪？
主数据在 `~/BobWork/`（项目在 `BobWorkspace/`，日历/收件箱/用量为全局库）；笔记库在 `~/BobWork/extensions/bob-notes-mcp/notes/`。

### 误删了会话怎么办？
左栏 Trash 图标打开回收站，可恢复或彻底删除。

### 怎么检查更新？
左栏底部版本号按钮 / NodeMap 上方状态图标；下载完会提示 Restart Now / Later。

### 怎么绑定微信？
设置 → Extensions → WeChat Bind 扫码绑定；之后文字、图片、语音、文件消息都会与桌面画布同步。

### 主题可以换吗？
BobWork 使用统一紫色主题（Purple），App / 小程序 / Widget 同一组色彩 Token；可在设置 → Theme & Appearance 查看。

### 小程序配色跟随主题吗？
跟随。小程序消费宿主注入的 `var(--brand)` / `var(--surface)` 等 CSS 变量，亮/暗（`data-bob-dark`）自动适配。
