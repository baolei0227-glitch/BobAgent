## 一、BobAgent 是什么

BobAgent 是一个运行在你电脑上的 AI 知识画布桌面应用。

它的核心概念是**无限画布 + AI 对话节点**：你可以在一个可以无限缩放、平移的画布上创建 AI 对话节点，每个节点是一个独立的 AI 对话。节点之间可以用线条连接，形成知识图谱——上游节点的总结会自动注入到下游节点的上下文中。

和普通聊天应用最大的区别是：
- **画布式组织**：不是线性聊天列表，而是可视化的节点网络，拖拽连线就能建立知识关系
- **本地存储**：所有数据存在你自己的电脑上（`~/BobAgent/`），不经过第三方服务器
- **多项目支持**：可以创建多个项目，每个项目有独立的节点、文件、日历和数据库
- **每个节点独立配置**：不同节点可以选不同的 AI 模型、不同的思考深度、不同的技能

### 核心工作流

1. 在画布上双击或拖拽创建新节点
2. 在节点里和 AI 对话，流式查看回复
3. 把相关节点连起来，形成知识网络
4. 下游节点自动获取上游节点的摘要作为上下文

## 二、开始使用

### 首次打开

1. 打开 BobAgent 后，如果没有项目，会显示欢迎引导页面
2. 输入项目名称，点击创建
3. 项目创建后进入画布主界面
4. 点击左下角齿轮图标进入设置，配置 AI 模型供应商

### 配置 AI 模型

BobAgent 支持 6 个模型供应商：

| 供应商 | 说明 |
|--------|------|
| DeepSeek | deepseek-chat (V3)、deepseek-reasoner (R1) |
| GLM (智谱) | glm-4-flash、glm-4-plus、glm-z1-flash |
| Moonshot | kimi-k2-thinking、moonshot-v1-8k |
| Qwen (通义千问) | qwen-max、qwen-vl-max (视觉) |
| OpenAI | gpt-4o (多模态)、gpt-4o-mini |
| Doubao (豆包) | doubao-1.5-vision-pro-32k |

设置步骤：
1. 点击设置 → 选择一个供应商
2. 填入 API Key
3. 点击"获取模型"自动拉取可用模型列表
4. 勾选要启用的模型
5. 可展开查看每个模型的详细规格（能力、优缺点、价格、上下文窗口）

### 三种模型角色

- **聊天模型**：主力模型，负责每个节点里的对话。每个节点可以独立选择
- **视觉模型**（可选）：当聊天模型不支持图片时，用一个多模态模型先把图片转成文字描述，再交给聊天模型理解。设置 → 视觉模型
- **任务总结模型**（可选）：WANTED 面板中用来将自由文本总结为结构化任务的模型。设置 → WANTED 模型

每个节点左上角有模型选择器，可以临时切换当前节点的模型。节点头部有思考深度选择器（关闭/低/中/高）。

## 三、画布操作

### 基本操作

- **平移画布**：鼠标拖拽空白区域
- **缩放画布**：鼠标滚轮，或右下角 +/- 按钮
- **创建节点**：双击画布空白处，或从已有节点拖拽连接手柄到空白处
- **连接节点**：从一个节点的底部手柄拖到另一个节点的顶部手柄
- **框选**：在画布上按住鼠标拖出矩形框，选中多个节点后可点击"+ Create Node"创建连接到所有选中节点的新节点

### 节点关系

节点之间的连线有两种关系：
- **并列 (sibling)**：平行连接，表示两个节点是相邻关系
- **子节点 (child)**：上下连接，把下方节点拖到上方节点正下方时会自动转换

已断开连接的边会显示警告图标。

### 节点管理

- 每个节点右上角有关闭按钮，点击删除节点
- 节点标题可自动生成（AI 建议标题时自动更新）

## 四、在节点中对话

### 基本操作

- **发送消息**：在输入框输入文字，按 Enter 发送
- **换行**：Shift + Enter
- **停止回复**：AI 回复过程中点击停止按钮
- **复制消息**：鼠标悬停在用户消息上显示复制按钮

### 模型选择

每个节点顶部有模型下拉菜单，按供应商分组显示已启用的模型。支持"自动模式"——AI 根据任务类型自动选择最合适的模型。

### 思考深度

节点标题栏有思考深度选择器：
- **关闭**：不显示思考过程
- **低 / 中 / 高**：逐步深入，思考过程可展开查看

### 技能（Skills）

每个节点可以独立选择要启用的技能：
- 点击节点底部的技能按钮，从下拉菜单勾选
- 已选技能显示为可移除的标签
- 在输入框输入 `/` 可以快速调出技能菜单

### 附件

- 点击回形针按钮上传文件，或粘贴、拖拽文件
- 支持的格式：图片、文本文件、PDF
- 附件预览显示在输入框上方，发送前可以移除
- 上传的图片会自动通过视觉模型（如已配置）转为文字描述

### @ 文件引用

在输入框输入 `@` 会弹出项目 materials 文件夹中的文件列表，可以用键盘上下选择、回车确认，引用文件内容。

### 工具调用

AI 在执行操作时会显示工具调用块：
- 可展开查看工具名称、参数、结果、耗时
- 支持的工具：`read_upstream_node`（读取上游节点）、`read_attachment`（读取附件）、`read_material`（读取素材文件）

### 问答弹窗

AI 回复中可能嵌入问题列表（`<!-- QUESTIONS -->...<!-- /QUESTIONS -->`），系统会自动提取为弹窗：
- 选择题和自定义回答
- 提交后自动作为追问发送

### 心情（Mood）

AI 回复后会在节点中显示心情数据：Vibe、Sparks、Reflections、Will 四个维度。

## 五、侧边栏

### 项目管理

侧边栏顶部显示当前项目名称。点击可展开项目列表：
- **切换项目**：点击项目名称切换到其他项目
- **新建项目**：点击 + 按钮，输入名称创建
- **删除项目**：点击垃圾桶图标，确认后删除（会同时删除所有节点和数据）
- 所有项目（包括默认项目）都可以删除；删除最后一个项目后显示欢迎引导页

### 文件浏览

项目文件以树形结构展示，支持：
- 展开/折叠文件夹
- 文件类型图标和颜色标签（MD、JSON、TS、JS、PY、CSS、IMG）
- 点击文件名在 FileViewer 中打开

### WANTED 任务面板

侧边栏中的可折叠面板，用于将自由文本转化为结构化任务：

1. 在文本框中粘贴任务描述（可以是一段话、会议记录、待办列表）
2. 点击 AI 总结按钮，系统会调用任务总结模型
3. AI 提取出：任务标题、开始时间、结束时间、优先级（高/中/低）、描述
4. 模糊无法解析的条目会单独列出
5. 点击"导入日历"将任务批量添加到日历

标题栏上的日历图标可以快速打开日历面板。

### 底部菜单

- **齿轮图标**：打开设置
- **技能图标**：打开技能管理器
- **刷新图标**：检查更新
- **Bug 图标**（开发模式）：打开开发者工具

## 六、日历

### 打开方式

- 点击 WANTED 面板标题栏的日历图标
- 通过侧边栏进入

### 功能

- **月视图**：显示当前月份，有事件的日期显示状态图标
- **导航**：左右箭头切换月份
- **创建事件**：点击日期创建新事件
- **编辑事件**：点击已有事件编辑
- **事件字段**：标题、描述、地点、开始/结束时间、全天开关、优先级（高/中/低）、标签、颜色
- **删除事件**：编辑界面中有删除按钮

### 从 WANTED 导入

WANTED 面板中 AI 总结出的任务可以直接批量导入日历。

---

## 七、Markdown 阅读器

每个节点对应一个 .md 文件，点击节点可以打开 Markdown 阅读器（右侧滑出面板）。

### 显示内容

- **摘要**：AI 自动生成的内容总结（只读）
- **对话记录**：完整的问答记录，包含时间戳和用户附件（可编辑，点击铅笔图标在 textarea 中编辑 markdown）
- **批注**：用户批注（可编辑）
- **便签**：用户便签，可添加/删除（可编辑）
- **标签**：节点的标签
- **来源**：上游节点的引用
- **心情**：Vibe、Sparks、Reflections、Will 数据

### 多标签

支持同时打开多个节点的 Markdown 阅读器，标签切换。

## 八、文件查看器

点击侧边栏文件树中的文件，会弹出文件查看器浮窗：
- **文本文件**：语法高亮显示
- **Markdown**：渲染预览
- **图片**：直接预览
- **二进制文件**：提供下载链接
- 显示文件元数据（名称、类型、大小）

## 九、设置

点击左下角齿轮图标打开设置面板。

### 模型供应商

- 选择供应商 → 输入 API Key → 获取模型 → 勾选启用
- 查看模型详情（能力标签、优缺点、适用场景、价格、上下文窗口）
- 新增模型会自动生成规格说明（优先 AI 生成，回退规则推断）

### 视觉模型

- 独立配置：选择供应商、输入 API Key、获取模型、单选
- 用途：当聊天模型不支持图片时，用视觉模型先把图片转文字
- 必须选择真正的多模态模型

### WANTED 模型

- 独立配置：选择供应商、输入 API Key、获取模型、单选
- 用途：WANTED 面板的任务总结和分类
- 如果未配置，会自动回退到第一个可用的聊天模型

### 技能管理

- 查看所有已安装的技能，按分类显示（内置、飞书/Lark、文档处理、设计、开发、其他）
- 展开分类查看技能列表
- 每个技能显示：名称、描述、来源（内置/用户）
- 启用/禁用单个技能
- 全部启用 / 全部禁用按钮
- 刷新按钮重新加载技能列表

## 十一、数据存储与安全

### 存储位置

所有数据存储在 `~/BobAgent/` 目录下：
- `.projects.json`：项目列表和当前项目
- `projects/<project_id>/nodes/`：每个节点的 .md 文件
- `projects/<project_id>/project.db`：SQLite 数据库（边、日历事件、会话）
- `projects/<project_id>/materials/`：项目素材文件
- `projects/<project_id>/assets/`：节点附件
- `skills/`：技能文件

### 数据格式

- .md 文件包含 YAML frontmatter（node_id、标题、时间戳、来源、模型、心情、标签）和固定四段（摘要、对话记录、批注、便签）
- .md 文件名格式：`<主题>-<YYYYMMDD>.md`
- 所有数据不经过第三方服务器（API 调用除外，那是你自己配置的模型供应商）

## 十二、实用技巧

### 建立知识网络

把相关话题的节点连接起来——上游节点的摘要会自动注入下游节点的上下文，适合深入分析和多轮研究。

### 用 WANTED 管理任务

粘贴会议记录或待办文本到 WANTED 面板，一键总结为结构化任务并导入日历。

### 不同节点用不同模型

简单对话用便宜的模型（如 glm-4-flash），复杂分析用强推理模型（如 deepseek-reasoner）。

### 用 @ 引用素材

把参考文档放到项目 materials 文件夹，对话中输入 @ 即可引用，无需复制粘贴。

### 框选批量操作

拖拽框选多个节点后，可以一键创建连接到所有选中节点的新节点，适合做汇总或对比分析。

### 自动模式

不确定用哪个模型时，选择自动模式让系统根据任务类型自动匹配。

## 常见问题

### 怎么添加模型？
设置 → 选择供应商 → 输入 API Key → 获取模型 → 勾选要用的模型。

### 视觉模型是干什么的？
当你的聊天模型不支持图片时，视觉模型会先把图片转成文字描述，再交给聊天模型。需要配置真正的多模态模型。

### WANTED 模型没配置怎么办？
系统会自动回退到第一个可用的聊天模型来完成任务总结。

### 怎么切换项目？
点击侧边栏顶部的项目名称，在下拉列表中点击目标项目。

### 节点之间怎么连线？
从一个节点的底部圆形手柄拖到另一个节点的顶部手柄。

### 怎么删除节点？
点击节点右上角的 X 按钮。删除节点同时删除对应的 .md 文件。

### 数据存在哪里？
`~/BobAgent/` 目录，所有数据在本地。

### 怎么检查更新？
点击侧边栏底部菜单的刷新按钮，或等待应用启动时自动检查。
