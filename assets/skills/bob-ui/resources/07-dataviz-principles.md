# 数据图设计原则（L3 按需资源 · widget:chart / antv / svg 数据图专用）

> 适用：任何带数据、坐标轴、序列的 widget。06-aesthetic-design.md 负责"怎么好看"，本文件负责"数据图怎么做才**正确、可读、诚实**"。
> 来源：skill-data-visualization（Claude Code skill）+ awesome-visualization-guide（Tufte 原则提炼），按本体系裁剪整合。
> 引用场景：写柱/折/饼/散点/面积等数据图时对照；觉得图"数据对但不像数据图/像报表截图"时逐条检查。

## 0. 核心心法

**图是沟通工具，不是装饰。** 落笔前先回答：这张图讲什么故事？帮谁做什么决定？没有故事的数据图 = 数据填鸭。

---

## 1. 图表选型（先选对图，再谈美）

| 想表达的关系 | 推荐图 |
|---|---|
| 随时间变化（点少） | 折线图 |
| 随时间变化（系列多） | 小多组图（small multiples） |
| 类别比较 | 条形图（长标签改横向） |
| 部分→整体（≤5 类） | 饼图/环形图（慎用） |
| 部分→整体（>5 类） | 堆叠条形图 |
| 分布 | 直方图 / 箱线图 |
| 两变量相关 | 散点图 |
| 排名 | 点图 / 棒棒糖图 |
| 单一关键指标 | KPI 卡 + 迷你趋势线 |
| 流程 / 构成变化 | 桑基图 |

**饼图铁律**：各切片必须合计 100% + ≤4-5 类 + 叙事是"整体中某一块更重要"。拿不准就换条形图。

**小数据集 ≤20 项：表格往往优于图表**（精确数字直接呈现，不靠眼睛估）。

---

## 2. 坐标轴与刻度（诚实性起点）

- **定量轴默认从 0 开始**；截断基线会夸大细微差异。必须截断时显式标注"轴在 X 处截断"
- 刻度等间隔（按 1/2/5 取），多图并列时同方向用同一 scale（横向并列的 y 轴范围必须一致，否则单位长度不等、无法比较）
- 时间永远左→右
- 折线图长宽比：让关键线段斜率绝对值集中在 45° 附近（斜率差异最易分辨）
- **网格线：浅灰 `#e5e5e5`、细、越少越好，禁用黑色**；弱化网格才能突出数据
- 时序数据给足比较上下文，别只截一小段（无比较易得偏颇结论）

---

## 3. 色板纪律（适配本体系 Purple family）

> 本体系数据系列默认用 Purple family 深浅分层（`#4b3fe3 / #6f6fff / #a9aeff / #d3d4da`）。需要更多区分时按下方原则扩展，但保持同一家族的低饱和调和——不引入跳跃的行业色板。

- **Categorical（类别区分）**：用不同色相，不用渐变；色盲最安全起点 = 蓝 + 橙/红。5-6 类先加深/变浅已有色相，7+ 类合并成"Top N + 其他"或拆小图
- **Sequential（低→高）**：单色相、明度由浅到深渐变，配对主色与浅变体
- **Divergent（负→中→正）**：两端两个对比色相 + 中性中点（红-中性-蓝 / 橙-中性-青，后者色盲安全）
- **Highlight（强调）**：只用一个强调色，其余全部转灰——与 07「单一焦点」一致
- **CVD 色盲安全**：首选蓝+橙 / 蓝+红组合；**禁止用红+绿作为唯一区分**（约 8% 男性受影响）
- **颜色总量 ≤20 种**（视觉记忆上限）；分类色 ≤5-7 类
- 鲜艳/高饱和色 = "重音"，只做少量、分散的强调，**严禁大面积集中使用**（通篇重音 = 没有重音，且造成视觉负担）
- 背景用偏灰偏暗的中性色，能让鲜艳图形和谐共处、降低混乱感

---

## 4. 标注与图例

- **标题传达结论，不只描述数据**：`"7 月销售额突破 3000 万"` 优于 `"各月销售额"`（副标题给一句关键洞察）
- ≤4 系列优先**直接标注**（线尾/条旁），不用远端图例（减少"颜色→图例"的匹配负担）
- 图例放图顶部，顺序与图中一致
- 坐标轴两侧都要有标签 + 单位
- 时间序列的关键事件（上线、政策、异常点）用 callout/注解线说明，异常点给 inset 放大图或文字解释

---

## 5. 诚实性与伦理（Tufte 硬约束 · 违反即返工）

- **图形尺寸与数值成正比**：不用面积表示一维数值（气泡面积翻倍会被感知成"4 倍"）
- **维度数不超数据维度**：一维数值别用二维图形表达，避免夸大
- **数据-墨水比例**：删掉所有不承载数据的墨迹（装饰性网格、纯装饰边框、3D）
- **小数据集用表格**（≤20 项，见 §1）
- **标注不确定性与误差**：有置信区间/误差范围就画出来；隐藏不确定性的"干净图"是误导
- 注明**数据来源**（底部注记，叙事闭环）
- 相同指标在同一发布中颜色恒定（同一颜色 = 同一变量）；数据有缺失时，缺失本身就是故事，标注出来

---

## 6. 排版与无障碍

- 图表文字一律**无衬线** + **tabular numbers**（等宽数字，数字列/坐标轴精确对齐；CSS：`font-variant-numeric: lining-nums tabular-nums`）
- 字号：轴标签 12-14 / 标题 14-16 bold / 注解 11-13；最小 12px
- 文本尽量左对齐（标题、图例居中）
- 标记与背景对比度 ≥ 3:1（WCAG）
- **不单靠颜色传达信息**：补直接标注、图案纹理（hatching/dots，SVG `<pattern>` 或 CSS clip-path）
- SVG 无障碍：根节点 `role="img"` + `aria-label`，内置 `<title>`/`<desc>`；复杂图提供数据表格替代

---

## 7. 数据图快速清单（Pocket · 输出前过一遍）

```
✅ 图有单一清晰消息（标题=结论）
✅ 定量轴含 0（或显式标注截断）
✅ 网格线浅灰 #e5e5e5、细、少
✅ 刻度等间隔、多图同 scale
✅ 色板按 Categorical/Sequential/Divergent 选对
✅ 色盲安全（蓝+橙，无红绿唯一区分）
✅ 颜色 ≤20 种、鲜艳色仅少量强调
✅ 无衬线 + tabular numbers、最小 12px
✅ ≤4 系列直接标注 / 5+ 用顶部图例
✅ 坐标轴有标签与单位
✅ 来源已注明
✅ 图形尺寸与数值成比例、无 3D、无冗余墨迹
✅ 异常点/截断/不确定性已说明
✅ 数据排序为叙事服务（非默认序）
```
