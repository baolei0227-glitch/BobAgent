# 密度预算 · 版式规范 · 5 种布局模式（L3 按需资源）

> 处理"图里塞太多""排版不一致""对齐混乱"。L2 只要求遵守密度上限和选模式，此处是具体对照。

## 1. 密度预算（硬上限）+ 焦点层级

一张 widget 图（或一组相邻图）最多：
- **焦点 ≤1**：优先级 **位置(左上/几何中心) > 尺寸(>其他 1.5 倍) > 颜色(唯一焦点才 accent，其余全中性)**。**形状先于颜色**：起始跑道形、决策菱形本身即焦点语义，勿再给所有决策节点上 accent。**禁止三重叠加**（加粗+变色+放大+阴影，最多 2 种组合）
- **主节点/主系列 2-5 个**；超→分组 / 折叠成"Top N+其他" / 拆多张图
- **含义色 ≤2**（不含中性灰/黑/白）；同义数据必须同色
- **交互概念 ≤1**/图（tooltip / 点击 / tab 切换三选一，不混用）
- 信息层级 ≤3（焦点/主体/辅助），靠字号梯度+间距区分

## 2. 网格系统（HTML 强制，SVG 按 viewBox 同原则）

- 响应式栅格（唯一多列写法）：`repeat(auto-fit, minmax(140px, 1fr))`；方案对比卡 `minmax(200px,1fr)`、概览条目 `minmax(160px,1fr)`；**禁 `grid-template-columns: 1fr 1fr 1fr`**（卡死列数窄屏溢出）
- KPI 行 2-4 列、栏距 12px；≤2 列改横向 flex
- 卡片网格 ≤3 列；>3 转横向滚动（不推荐）/折叠成 Tab
- 正文列宽 ≤640px；图表 ≤680px（与 SVG viewBox 对齐）；卡片嵌套 ≤2 层

## 3. 对齐（强制一致，不混搭）

| 对象 | 对齐方式 |
|---|---|
| 中文正文/标题 | **左对齐**（禁两端对齐，字距撕裂） |
| 数字/金额/KPI 值 | 右对齐或居中，**同组内保持一致** |
| 标签+数值 | label 上 / value 下堆叠（不用左右并排） |
| 图标+文字 | 基线对齐或垂直居中 |
| 列表/图例 | 左对齐，间距 8px；图例靠左或顶部，不放右下 |

## 4. 垂直节奏（HTML 强制）

8px 基准：小元素 8 / 块级 16 / 版块 24；标题下留 8-12px（标题档越低留越少）。间距一律取 `--widget-space-*` 标尺（见 01-style-rulers.md）。

## 5. 布局模式库（5 预设 · 禁止 ad-hoc 拼凑）

先判信息类型 → 对号入座 → 直接用对应结构。

**模式 1 · KPI 行**（3-6 指标）：grid 2-4 列（auto-fit minmax 140px）→ `.w-kpi`×N（`.label` caption 档灰 / `.value` headline 档 accent 或 series-1）；同组 KPI 不红绿混杂；可选 `.w-tag` 同比/环比徽标（成功绿/警告橙）

**模式 2 · 卡片网格**（方案对比/条目列举，3 层结构以上）：grid ≤3 列（auto-fit minmax 200px）→ `.w-card`（`.w-title` + 摘要 body 1-3 行 + `.w-tag` 行 + 可选 `.w-btn--primary`）；推荐项加 `border:2px solid var(--widget-accent)` 或 accent 5% 底，勿整卡 accent；各卡信息密度完全对齐

**模式 3 · 图文混排**（数据+解读）：上下堆叠 gap 16px → 图（widget:chart/svg 宽 100%）→ caption 档来源/单位标注（11px 灰左对齐）→ 解读（body ≤3 行或 2-3 bullet）；图注在图下 ≥8px；解读只讲"为什么/所以怎么办"，不重复图面事实

**模式 4 · 对比并排**（A/B PK）：flex 两栏 1:1 gap 12px → 两 `.w-card`，推荐项加 2px accent 边框；两卡**行数/标题/标签位置完全一致**便于横向比较；维度标签用 `.w-tag` 中性色，结论差异才用 accent/语义色

**模式 5 · 流程步骤**（≤5 步）：横向 flex justify-between → 步骤点（数字 accent 圆点 + 标题 + 描述 body-sm）──连线──步骤点；关键转折点 accent 填充（唯一焦点）、终态 success 绿；**>5 步不要硬拼 HTML，直接写 widget:mermaid flowchart**

## 6. 图例与来源标注

图例在图表**顶部/右上**，label 档 12px muted 色；来源/单位在**底部左对齐** caption 11px；估算数据标「约」；图注与图表间距 ≥8px

## 7. 响应式/容器安全

HTML widget 宽度自适应 iframe；栅格**禁固定列数**；内层元素写 `minmax(0, 1fr)` 防长文字/链接撑破容器；禁固定 `min-width`；窄容器（<420px）自动转单列
