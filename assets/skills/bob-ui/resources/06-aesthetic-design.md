# 审美设计原则（L3 按需资源 · 让 widget 从"合规"到"好看"）

> 适用：任何 widget 输出前。合规规则（标尺/密度/颜色纪律）保证"不出错"，本文件负责**"怎么好看"**。
> 输出前把本文件过一遍：先定视觉焦点与版面，再落数据与文字——顺序反了就会得到"表格加个框"。
> 引用场景：觉得图"中规中矩/没设计感/像报表截图"时，逐条对照本文件修改。

## 0. 一句话心法

**好看 = 明显的视觉层级 + 克制的留白 + 一个视觉焦点 + 精致的细节。** 四者缺一不可。

---

## 1. 视觉层级：用"大小/对比/留白"分主次，而不是靠边框

平庸图的特征：所有元素同字号、靠边框和分隔线分区块——像文档截图。
优秀图的特征：扫一眼 2 秒内就知道"先看哪里、再看哪里"。

**层级三原则**
1. **字号阶梯要拉得开**：主标题 24-32 / 区块标题 14-16 / 正文 12-13 / 注记 10-11。差距 ≥ 1.5 倍才有"版面感"，全部挤在 12-14 就是报表
2. **一个维度突出即可**：关键数字同时放大 + 品牌紫 + 加粗（三个维度叠加 = 焦点），其余元素只用其中一个维度弱化（如标题只放大、次级文字只降明度）
3. **弱化靠"灰"不靠"小"**：次要信息用次级灰（`#52525b`/`#a1a1aa`）而不是一律 10px 小字——灰色降级比缩小更高级

**检查**：去掉所有边框后，视觉层次是否仍然成立？如果成立 → 层级 OK；如果靠边框才能分清 → 重排（用大小/留白/颜色重建层级）。

---

## 2. 留白与节奏：宁空勿挤

- **区块间距 ≥ 12，卡片内边距 ≥ 12**，四周留边 ≥ 20
- 关键数字周围留足"呼吸区"（数字与标签间距拉开，数字本身不贴边）
- **同一屏 ≤ 4 个信息块**；放不下就删内容、合并、或改两图，不要堆 6-7 块
- 留白不是浪费——它是"这是设计过的"与"这是填满的"的分界线

---

## 3. 单一视觉焦点：一张图只让一个主角

- 每张图**有且只有 1 个视觉焦点**（大数字 / 主标题 / 核心结论 / 主节点）
- 焦点 = 全图最大字号 + 品牌紫（或最大面积色块），其他元素主动"让位"（缩小、降灰）
- 反例：KPI 行 3 个数字全部品牌紫放大加粗 = 没有焦点；流程 6 个节点全上 accent 色 = 没有焦点
- 焦点位置习惯放在**左上标题区 / 顶部数字带 / 中心主节点**，符合阅读顺序

---

## 4. 现代设计语言（对标 Apple / Linear / Notion 质感）

| 维度 | 做 | 不做 |
|---|---|---|
| 扁平 | 平面色块 + 克制的层级 | 渐变、拟物、重阴影 |
| 阴影 | 极浅投影（`0 1px 2px rgba(0,0,0,.05)` 级） | `0 8px 24px` 重阴影 |
| 圆角 | 6/8/12/16 一致成体系 | 每块圆角都不一样 |
| 栅格 | 卡片等宽对齐、数字右对齐、文本左对齐 | 每列宽度随意 |
| 字体 | 无衬线、字号成档 | 衬线、字号随手写 |
| 装饰 | 几何图标/数据条/序号徽标/圆点引导线（见 §6） | 照片、emoji、复杂插画 |

**"Apple 感"三件套**：① 大标题留白多 ② 卡片圆角 12 + 1px 淡边框 + 极浅投影 ③ 主色只出现 1-2 处。

---

## 5. 排版张力：标题与数字是"版面"的主角

- **主标题**：字号 24-32、字重 700、可占两行换行（长标题用 `<tspan>` 断开成"上半句大 + 下半句次大"），制造杂志式排版
- **副标题行**：13-14px 次级灰，带主题标签（· 分隔）+ 时间/口径
- **关键数字**：28-36、tabular 对齐、单位放旁边小字；多个数字同排时**基线对齐**
- **标题与内容之间用留白分隔**，不用满幅横线（横线只做底部收尾）

---

## 6. 装饰细节工具箱（从"表格加框"变"作品"的最小改动）

以下元素每次只选 1-3 个，配合主题使用：

- **序号徽标**：圆形/圆角方块内放 ①②③ 或 01/02/03（品牌紫浅底 + 紫描边），用在流程/要点
- **数据条**：`<rect>` 圆角横条表示占比/进度（浅底 + 品牌紫填充），比纯数字直观
- **圆点引导线**：标题左侧竖线（3px 紫条）或横线圆点连接，标注分区
- **分区色块**：浅底块（brand-soft `#F2F7FF`）+ 圆角 12，承载一个语义分区
- **标签胶囊**：小圆角胶囊（品牌紫 12% 底 + 紫字），标注"同比/预估/口径"
- **几何图标**：圆环（外圈浅紫 + 内圈实心紫）、圆点、圆角矩形、线条箭头——**≤2 个元素**，不画复杂路径
- **底部注记**：来源 + 口径小字（10-11px 弱灰），收尾叙事闭环

**装饰不遮内容（可读性优先）**：高光 / 色块 / 引导线等装饰层若叠加在文字上，必须保证文字仍清晰——SVG 中先画装饰后画文字（装饰在底层），HTML 中装饰层用 `pointer-events:none` 且置于内容之下；任何使文字发白、对比度下降的装饰都是失败的，宁可去掉。

**反例**：不用 emoji、不用图片、不用复杂 SVG path 图标、不用渐变装饰。

---

## 7. 高级布局（跳出"卡片网格"同质化）

基础 5 模式（KPI 行/卡片网格/图文混排/对比并排/流程步骤）之外，信息图优先：

- **杂志式（Magazine）**：大标题置顶占 1/4 高，其下左大右小不对称分区（左 = 核心结论区，右 = 支撑数据），底部注记
- **锚点式（Anchor）**：中间一个主结论大色块（焦点），四周辐射 2-3 个支撑区块
- **数字带+分区（Band）**：顶部 2-4 个大数字横带（第一眼），下方 2-3 个浅色分区解读（自上而下叙事）
- **Z 型扫读（Z-Pattern）**：左上标题 → 右上副标/标签 → 中左要点 → 中右数据 → 底部结论，保证视线 Z 字移动

---

## 8. "丑 → 美"对照（最常见 3 例）

### 丑例 1：平铺报表
```
所有文字 13px 灰色、列表堆 6 项、无卡片无分区无焦点
```
→ 改：大标题 + 顶部关键数字带（28px 紫）+ 2 个浅紫分区 + 底部注记

### 丑例 2：全部突出
```
3 个数字全紫加粗放大、流程 6 节点全 accent
```
→ 改：只 1 个主数字紫放大（其余 2 个正常灰大号）；流程只起点焦点着色

### 丑例 3：挤满无留白
```
卡片贴卡片、文字贴边、分区间距 6px
```
→ 改：区块间距 ≥12、卡片内边距 ≥12、四周留边 ≥20，删掉 1-2 块次要内容

---

## 9. 3 秒审美自检（输出前最后一步 · 完整 7 条清单见 04-quality-checklist.md §4）

1. 第一眼抓人的是什么？（必须立刻能说出：大标题？大数字？主结论？——说不出 = 无焦点）
2. 去掉边框还分得清层次吗？（靠大小/对比/留白 = 好；靠线 = 重排）
3. 像"作品"还是像"截图"？（有装饰细节 + 排版张力 + 留白充足 + 文字清晰 = 作品；平铺/发白发虚 = 重做）

任意 1 条不过 → 修改后再输出，不急着交。
