## 1. 逐图自检（11 条，输出前逐条过）

输出 widget 前在心里打勾，任意 1 条未过就继续改，不要先回复。

| # | 检查项 | 判断标准 | 典型违规 |
|---|---|---|---|
| 1 | 唯一焦点？ | 有且只有 1 个视觉焦点；焦点由位置/尺寸/颜色中的**一种或两种**制造（不用三重叠加） | 所有节点都用了 accent 色；KPI 行的 3 个数字全用 accent 红加粗放大 |
| 2 | 无重叠/无出界/无线穿字？ | SVG：文字、节点、图例互不重叠，连接线不穿过节点/文字；所有元素在 viewBox 内留边 ≥20px。HTML：内容不溢出 grid，不出现横向滚动条（`auto-fit minmax` 能防） | 连接线从文字中间划过；节点被裁切掉一半；KPI 卡在窄屏出现滚动条 |
| 3 | 颜色纪律？ | 无荧光、无纯黑纯白铺满；深色下可读；系列色无"同物不同色/异物同色"混淆；语义色只在真实状态语义下上（不是因为词带成功失败） | 柱状 3 系列颜色和含义对不上（A 绿 B 红，但 B 明明是增长数据）；红绿色盲场景红绿紧挨没加图案/标签辅助 |
| 4 | **主题变量/系列色必写？** | HTML widget 顶部 `<style>` 必写 `--accent`（品牌 Purple `#4b3fe3`）等品牌 Purple 变量；chart 必写 `option.color`——**只输出渲染器默认灰底 = 成品不合格，属未完成重画** | 整块 widget 是灰底 + 默认 Purple 兜底、无品牌 Purple 主色强调；`option.color` 缺省 |
| 5 | 字号/间距/圆角取自标尺？ | 所有字号在 11/12/13/14/16/20/24 七档；间距在 4/8/12/16/24/32；圆角 4/6/8/12/16/pill | 出现 15px / 17px / 19px 字号；间距写 10px / 15px / 18px / 20px |
| 6 | 数据完整？ | 所有数值**带单位**；原始来源标清楚（估算要写「约」）；口径说明放在 caption | 写了 18% 同比但不说同比哪年；金额没 ¥/$；关键数据说"据统计"不标来源 |
| 7 | 系列数归并？ | ≤ 4 系列 + 1 个"其他"；超过 → Top N 归并 | 饼图 12 瓣、柱状 10 根（9 根都很矮） |
| 8 | SVG viewBox？ | viewBox 宽度 ≤ 680px；四周内边距 ≥ 20px；viewBox 不是 300×150 这种瘦条（除非就是 timeline） | viewBox 写 width="1200" height="800"；文字贴边被裁切 |
| 9 | HTML 复用 .w-* 类？ | 卡片、KPI、标签、按钮都用预置类，不要手写等价样式（`padding:12px 16px;border-radius:12px;border:1px solid #eee` 等价 `.w-card`） | 直接拼一堆 inline style 造出"看起来像 card"的 div |
| 10 | 信息层级 ≤ 3？ | 视觉层级分「焦点 / 主体 / 辅助」最多 3 级，没有第 4 层（比如焦点里再套焦点） | 卡片套了 3 层、每一层都有自己的标题/摘要/标签/按钮 |
| 11 | 布局对号入座 + 对齐一致？ | KPI/卡片网格/图文/对比/流程 5 种模式之一；文本左/数字右/KPI 居中不混搭 | 同一 KPI 行里第 1 个居中第 2 个右第 3 个左；列表一会儿左对齐一会儿右对齐 |

## 2. SVG 几何强制规则（除了自检还要满足）

1. **用 viewBox 规划坐标，不用纯 width/height**；`viewBox="0 0 <W> <H>"` 且 **W ≤ 680**
2. **四周内边距 ≥ 20px**（最外元素距 viewBox 四边 ≥ 20，留白透气）
3. **任何文字、节点、标签、图例不得重叠**；元素间距 ≥ 8px
4. **连接线**：圆角 L 弯（`rx/ry` 或 path 的 smooth Q/C）或平滑贝塞尔曲线；线不穿过节点和文字；箭头指向目标节点端（用 `marker-end`）
5. 不用 `overflow:hidden` / 背景大色块掩盖越界元素——放不下就**删减内容**或改回纯表格（仅允许术语/原文引用表那两个例外）
6. 不用 `<foreignObject>` 嵌 HTML 段落，SVG 里文字用 `<text>`；段落叙述放正文 widget:html，不在图里

## 3. 常见踩坑 5 例（「之前」→「正确」对照）

### 踩坑 1：用纯 Markdown 表格写对比，然后表格里还涂 inline 背景色假装卡片
```
| 方案 | 成本 | 推荐度 |
|---|---|---|
| A <span style="background:#E6EEF7">好</span> | <span style="color:red">¥10万</span> | ⭐⭐⭐⭐⭐ |
```
→ **改为 `widget:html` + `.w-card` 网格 + `.w-kpi`/`.w-tag`**，颜色通过 `<style>` 的 `--accent` 主题变量统一注入。

### 踩坑 2：Mermaid 流程图所有节点都用了 accent 色
"每个节点都想突出 = 没有节点突出"。
→ **只给起点（或关键决策节点）上焦点着色**，其余全中性；成功/失败终态才用语义色。着色见 `03-widget-examples.md` 着色层次表。

### 踩坑 3：HTML widget 栅格写死 3 列，窄屏容器溢出
```css
grid-template-columns: 1fr 1fr 1fr
```
→ **改响应式栅格**：`grid-template-columns: repeat(auto-fit, minmax(140px, 1fr))`

### 踩坑 4：把主题色 `#4b3fe3` 直接写在 widget 外正文里的 `<style>` 标签里
正文里 `<style>` 被安全过滤移除，样式不生效。
→ **把主题变量写在 `widget:html` 块的第一行 `<style>` 里**（沙箱内允许 `<style>`），不要写在正文。

### 踩坑 5：ECharts `option.color` 漏写，系列直接吃渲染器兜底
→ **必须手写 `option.color`**，即使你打算用 Purple 兜底组也必须抄一遍，表示你选过了。统一 Purple family 深浅分层（`#4b3fe3 / #6f6fff / #a9aeff / #d3d4da`），不是 7 色全用。

### 踩坑 6：widget:html 只输出裸 `<div>` + 黑字，无 `<style>` 主题变量、无 `.w-*` 类——渲染出来就是灰底黑字"简陋感"的来源
→ **三件套缺一不可**：① 块内第一行 `<style>` 写 `--accent` 等品牌 Purple 变量（正文会被过滤、widget 内合法必写）② 容器用 `.w-card`（渲染器已注入白卡+灰底层次）③ 数字/标签用 `.w-kpi`/`.w-tag`。输出前对照自检表第 4/9 条。

## 4. 美感自检（5 秒 · 完整原则见 06-aesthetic-design.md）

合规自检保证"不出错"，本节保证**"好看"**。任意 1 条不过 → 修改后再输出。

| # | 检查项 | 判断标准 | 平庸（要避免） |
|---|---|---|---|
| 1 | 第一眼有焦点？ | 2 秒内能说出"先看什么"（大标题 / 大数字 / 主结论），全图只 1 个焦点 | 所有数字同字号同色、所有节点同 accent——看不出重点 |
| 2 | 标题有版面感？ | 大标题（24-32、可两行断开/上下对比色）+ 副信息（标签胶囊/次行灰字） | 小标题 13px 一行带过，无排版张力 |
| 3 | 数字是第一眼？ | 关键数字 ≥24、tabular 对齐、基线一致、带单位 | 数字与正文同字号，淹没在文字里 |
| 4 | 去掉边框还分层？ | 层级来自大小/对比/留白，不是边框和分割线 | 全屏卡片+全屏边框才分得清区块 |
| 5 | 有装饰细节？ | 序号徽标 / 数据条 / 圆点引导线 / 标签胶囊 / 分区色块 ≥2 处（极简几何，不画复杂图标） | 纯文字平铺，一个装饰都没有 |
| 6 | 留白与节奏？ | 分区间距 ≥12、卡内边距 ≥12、四周 ≥20、不拥挤 | 卡片贴卡片、文字贴边、信息堆满 |
| 7 | 现代质感？ | 扁平 + 极浅阴影 + 圆角成体系 + 主色 1-2 处 | 渐变 / 重阴影 / 衬线 / 满屏紫 / emoji 当装饰 |
